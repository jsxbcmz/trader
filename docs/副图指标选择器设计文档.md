# 副图指标选择器 — 设计开发文档

## 1. 需求概述

当前四联图的 3 个副图（成交额、砖型差值、KDJ）固定展示，不可配置。需要新增一个下拉多选框，让用户自由勾选需要展示的副图指标：

- **最少 1 个，最多 3 个**
- 副图总高度保持不变（始终占 3/6 的比例）
- 主图（K线）高度自动占据剩余高度（始终为 3/6）
- 勾选变化后实时重新布局

## 2. 当前架构分析

### 2.1 文件结构

| 文件 | 职责 |
|------|------|
| `app/chart_layout.py` | PlotBundle/Items dataclass + 工厂函数，创建四联图布局 |
| `app/widgets.py` | StockChartWidget 主组件，数据更新 + 交互 |
| `app/chart_indicators.py` | 指标计算函数 |
| `app/chart_overlays.py` | HTML 浮窗/标签构建 |

### 2.2 当前布局方式

`create_chart_layout()` 使用 `QVBoxLayout` + stretch factor 排列四个面板：

```
chart_layout.addWidget(price_plot, 3)   # 主图，stretch=3
chart_layout.addWidget(vol_plot,   1)   # 副图1：成交额，stretch=1
chart_layout.addWidget(brick_plot, 1)   # 副图2：砖型差值，stretch=1
chart_layout.addWidget(kdj_plot,   1)   # 副图3：KDJ，stretch=1
```

总比例 = 3+1+1+1 = 6。主图占 3/6 = 50%，每个副图占 1/6。

### 2.3 关键耦合点

1. **X 轴联动**：`price_plot.setXLink(vol_plot)`, `brick_plot.setXLink(price_plot)`, `kdj_plot.setXLink(price_plot)` — 所有面板 X 轴同步
2. **鼠标事件**：`_on_mouse_moved()` 需要知道哪些面板可见，`_is_in_any_plot()` 遍历所有面板
3. **十字线同步**：`_set_crosshair_x()` 更新 4 个 vLine
4. **数据更新**：`set_daily()` 依次调用 4 个 `_update_*_panel()` 方法
5. **hover 标签**：`_update_hover_for_index()` 更新 brick/kdj 标签
6. **Y 轴联动**：`_update_visible_yrange()` 根据可见范围更新砖型/成交额的 Y 轴
7. **范围限制**：`_apply_xrange_limits()` 遍历所有面板设置 xMin/xMax

```
│  │                                               ││
```

**选择器行为规则：**
- 勾选变化实时生效
- 最后一个勾选项的 checkbox 置灰不可取消（保证最少 1 个）
- 默认全选 3 个

### 3.3 布局动态调整策略

核心原则：**副图总高度不变，均分给当前可见的副图**。

| 可见副图数 | 主图 stretch | 每个副图 stretch | 总 stretch |
|-----------|-------------|-----------------|-----------|
| 3 个 | 3 | 1 | 6 |
| 2 个 | 4 | 1 | 6 |
| 1 个 | 5 | 1 | 6 |

实现方式 — 使用 `QSplitter` 替代 `QVBoxLayout` 的 stretch：

**方案：保持 QVBoxLayout，通过 hide/show + 动态调整 stretch factor**

```python
def _update_sub_chart_visibility(self, visible_types: list[SubChartType]):
    """根据选中的副图类型更新布局。"""
    sub_chart_map = {
        SubChartType.VOLUME: (self.volPlot, self._vol_separator),
        SubChartType.BRICK:  (self.brickPlot, self._brick_separator),
        SubChartType.KDJ:    (self.kdjPlot, self._kdj_separator),
    }

    visible_count = len(visible_types)
    price_stretch = 6 - visible_count  # 主图占据剩余

    # 先设置主图 stretch
    self.chartLayout.setStretchFactor(self.pricePlot, price_stretch)

    for chart_type, (plot, separator) in sub_chart_map.items():
        if chart_type in visible_types:
            plot.show()
            separator.show()
            self.chartLayout.setStretchFactor(plot, 1)
        else:
            plot.hide()
            separator.hide()
            self.chartLayout.setStretchFactor(plot, 0)

    # 重新设置 X 轴联动
    self._relink_x_axes(visible_types)
```

### 3.4 X 轴联动重建

隐藏面板后需要重建 X 轴联动链，确保可见面板之间仍然同步：

```python
def _relink_x_axes(self, visible_types: list[SubChartType]):
    """重建可见面板之间的 X 轴联动。"""
    # 先解除所有联动
    for plot in (self.volPlot, self.brickPlot, self.kdjPlot):
        plot.setXLink(None)

    # 所有可见副图都链接到主图
    type_to_plot = {
        SubChartType.VOLUME: self.volPlot,
        SubChartType.BRICK:  self.brickPlot,
        SubChartType.KDJ:    self.kdjPlot,
    }
    for chart_type in visible_types:
        type_to_plot[chart_type].setXLink(self.pricePlot)
```

### 3.5 数据更新适配

`set_daily()` 中只更新可见面板的数据：

```python
def set_daily(self, df):
    # ... 省略前置处理 ...
    self._update_price_panel(x, o, h, l, c, is_up)

    if SubChartType.VOLUME in self._visible_sub_charts:
        self._update_volume_panel(x, is_up, amount_yi)
    if SubChartType.BRICK in self._visible_sub_charts:
        brick_values = self._update_brick_panel(x, h, l, c)
        self._update_brick_green_thresholds(h, l, c, brick_values)
    else:
        # 仍需计算 brick_values 供主图临界线使用
        brick_result = compute_brick_indicator(h, l, c)
        brick_values = brick_result["brick"]
        self._brick_values = brick_values
        self._update_brick_green_thresholds(h, l, c, brick_values)
    if SubChartType.KDJ in self._visible_sub_charts:
        self._update_kdj_panel(x, h, l, c)
```

**注意**：即使砖型差值面板隐藏，`_brick_values` 仍需要计算，因为主图的绿砖临界价格线依赖它。

### 3.6 交互适配

#### 3.6.1 鼠标事件

`_is_in_any_plot()` 和 `_on_mouse_moved()` 只检查可见面板：

```python
def _is_in_any_plot(self, pos) -> bool:
    if self.pricePlot.sceneBoundingRect().contains(pos):
        return True
    for chart_type in self._visible_sub_charts:
        plot = self._type_to_plot[chart_type]
        if plot.sceneBoundingRect().contains(pos):
            return True
    return False
```

### 3.7 SignalProxy 管理

鼠标事件代理需要在面板 show/hide 时保持正确。由于 pyqtgraph 的 SignalProxy 绑定到 scene 的 `sigMouseMoved`，隐藏的面板不会收到鼠标事件，所以无需断开/重连，仅需在 `_on_mouse_moved` 入口判断面板可见性即可。

### 3.8 十字线日期标签定位

`_update_crosshair_date()` 当前使用 `self.kdjPlot` 做坐标映射。如果 KDJ 面板隐藏，需要改用最下方的可见面板：

```python
def _get_bottom_visible_plot(self) -> pg.PlotWidget:
    """获取最下方的可见副图，用于十字线日期标签定位。"""
    ordered = [SubChartType.KDJ, SubChartType.BRICK, SubChartType.VOLUME]
    for t in reversed(list(SubChartType)):
        if t in self._visible_sub_charts:
            return self._type_to_plot[t]
    return self.pricePlot
```

## 6. SubChartSelector 组件设计

```python
class SubChartSelector(QToolButton):
    """副图指标多选下拉框。"""

    selectionChanged = Signal(list)  # 发射 list[SubChartType]

    def __init__(self, parent=None):
        super().__init__(parent)
        self.setText("副图指标 ▼")
        self.setPopupMode(QToolButton.InstantPopup)

        self._menu = QMenu(self)
        self._checkboxes: dict[SubChartType, QCheckBox] = {}

        for chart_type in SubChartType:
            meta = SUB_CHART_META[chart_type]
            checkbox = QCheckBox(meta["label"])
            checkbox.setChecked(True)
            checkbox.stateChanged.connect(self._on_checkbox_changed)

            action = QWidgetAction(self._menu)
            action.setDefaultWidget(checkbox)
            self._menu.addAction(action)
            self._checkboxes[chart_type] = checkbox

        self.setMenu(self._menu)

    def _on_checkbox_changed(self):
        selected = [t for t, cb in self._checkboxes.items() if cb.isChecked()]

        # 保证最少 1 个：如果只剩 1 个，禁用其 checkbox
        for t, cb in self._checkboxes.items():
            cb.setEnabled(len(selected) > 1 or cb.isChecked())

        self.selectionChanged.emit(selected)

    def get_selected(self) -> list[SubChartType]:
        return [t for t, cb in self._checkboxes.items() if cb.isChecked()]

    def set_selected(self, types: list[SubChartType]):
        for t, cb in self._checkboxes.items():
            cb.blockSignals(True)
            cb.setChecked(t in types)
            cb.blockSignals(False)
        self._on_checkbox_changed()
```

## 9. 风险与注意事项

1. **X 轴联动解除/重建**：pyqtgraph 的 `setXLink(None)` 需验证是否能完全解除联动，避免隐藏面板仍干扰可见面板的范围计算
2. **面板 hide 后重新 show**：确认 pyqtgraph PlotWidget 的 show/hide 不会丢失已设置的数据和图形项
3. **砖型差值计算**：即使面板隐藏，`_brick_values` 仍需计算（主图临界价格线依赖）
4. **SignalProxy**：隐藏面板的 scene 不再接收鼠标事件，但 proxy 对象仍存在，不会有性能问题
5. **首次加载顺序**：需要在 `create_plot_bundle()` 之后、`set_daily()` 之前设置初始可见状态
6. **选股页兼容**：选股页的 `StockChartWidget` 是独立实例，需要独立配置或共享 QSettings
