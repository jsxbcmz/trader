# 金策智算（jin-ce-zhi-suan）项目深度分析与借鉴

## 一、项目概述

**金策智算** 是一个完整的 A 股量化回测 + 实盘监控系统，采用唐朝"三省六部制"的架构隐喻来组织代码模块。技术栈为 **Python + FastAPI + Web Dashboard**，支持多策略并行回测、风控审核、实盘监控等功能。

### 技术栈

| 层面     | 技术选型                                    |
| -------- | ------------------------------------------- |
| 后端框架 | FastAPI + Uvicorn                           |
| 前端     | 纯 HTML Dashboard（`dashboard.html`）     |
| 数据库   | DuckDB / MySQL / PostgreSQL                 |
| 数据源   | AkShare / Tushare / 通达信 TDX / 自定义 API |
| AI 能力  | SiliconFlow（Qwen3-30B）策略进化            |
| 桌面端   | PyInstaller 打包（`desktop_launcher.py`） |

### 核心依赖

```
pandas, numpy, tqdm, matplotlib, mplfinance

requests, tushare, akshare, pytdx, mootdx
```

## 二、架构设计详解

### 2.1 整体架构流程

```
行情数据源 → 太子院(CrownPrince) → 中书省(ZhongshuSheng) → 门下省(MenxiaSheng) → 尚书省(ShangshuSheng)
                数据校验分发           策略信号生成           风控审核(可否决)        执行清算
```

### 2.2 三省（决策主链路）

#### 太子院 CrownPrince — 数据前置校验

- **文件**：`src/core/crown_prince.py`
- **职责**：接收原始行情数据，做合法性校验（ST股过滤、涨跌停检测、数据完整性检查），分发给后续模块
- **类比**：数据入口的"门卫"

#### 中书省 ZhongshuSheng — 策略信号生成

- **文件**：`src/core/zhongshu_sheng.py`
- **职责**：持有所有策略实例列表，逐 bar 调用每个策略的 `on_bar(kline)` 方法，收集买卖信号
- **核心逻辑**：
  - 遍历所有策略，调用 `strategy.on_bar(kline)`
  - 如果策略返回信号，校验 qty（数量），不合法则跳过
  - 支持按 `strategy_ids` 过滤只运行部分策略
  - 回测时通过 `set_backtest_context()` 注入当前可用资金等上下文

```python
def generate_signals(self, kline, runnable_strategy_ids=None, strategy_context=None):
    signals = []
    for strategy in self.strategies:
        signal = strategy.on_bar(kline)
        if signal:
            signals.append(signal)
    return signals
```

#### 门下省 MenxiaSheng — 风控审核一票否决

- **文件**：`src/core/menxia_sheng.py`
- **职责**：对每一个交易信号做**强制风控审核**，不合格直接否决
- **风控规则**：

| 规则编号 | 规则名称     | 默认阈值 | 说明                                 |
| -------- | ------------ | -------- | ------------------------------------ |
| R1       | 单笔止损幅度 | ≤ 10%   | `abs(entry - stoploss) / entry`    |
| R2       | 单票仓位上限 | ≤ 100%  | `position_value / portfolio_value` |
| R3       | 总仓位上限   | ≤ 100%  | 所有持仓市值/总资产                  |
| R4       | 日亏损熔断   | ≤ 5%    | 当日累计亏损达阈值，禁止开新仓       |
| R5       | 连续亏损停仓 | 连亏3次  | 连续亏损达次数后暂停开仓             |

- 所有参数可通过 `config.json` 的 `risk_control` 节点动态调整
- 被拒绝的信号会记录到**刑部**（`XingBuJustice`），可追溯审计

#### 尚书省 ShangshuSheng — 执行与清算

- **文件**：`src/core/shangshu_sheng.py`
- **职责**：接收通过风控的信号，执行模拟撮合，管理持仓和资金
- **关键实现**：
  - **T+1 结算**：买入当天不可卖出，通过 `lots` 机制（每笔买入记录独立的 `buy_day`）精确管理
  - **FIFO 卖出**：`_consume_lots_fifo()` 按先进先出规则消耗持仓
  - **交易成本**：佣金(0.025%) + 印花税(0.1%) + 滑点(0.1%)
  - **持仓重建**：`_rebuild_position_from_lots()` 从 lots 重新计算均价、市值

```python
# T+1 可卖数量计算
def _sellable_qty_t1(self, pos, curr_day):
    lots = self._ensure_lots(pos)
    return sum(lot['qty'] for lot in lots if lot['buy_day'] != curr_day)
```

## 三、核心功能模块详解

### 3.1 回测引擎 BacktestCabinet

**文件**：`src/core/backtest_cabinet.py`

这是整个系统最核心的模块，提供完整的事件驱动回测能力。

**核心特性**：

- 支持**单票回测**和**多策略并行**
- 每策略独立分配资金：`strategy_initial_capital = total_capital / strategy_count`
- 逐 bar 推进（支持 1min 到日线各周期）
- 异步事件回调机制（WebSocket 实时推送进度）
- 支持**组合回测**（`combination_config`）
- 回测结果包含：ROI、年化收益、最大回撤、胜率、盈亏比、夏普比率、卡玛比率

**回测主循环伪代码**：

```python
for each bar in market_data:
    # 1. 太子院 - 数据校验
    validated = crown_prince.validate(bar)
  
    # 2. 中书省 - 策略产生信号
    signals = zhongshu_sheng.generate_signals(bar)
  
    for signal in signals:
        # 3. 门下省 - 风控审核
        approved, reason = menxia_sheng.check_signal(signal, ...)
      
        if approved:
            # 4. 尚书省 - 执行撮合
            shangshu_sheng.execute_order(signal, bar)
  
    # 5. 检查止损/止盈
    shangshu_sheng.check_stops(bar)

# 6. 礼部 - 生成报告和排名
rites.generate_report(...)
rites.generate_ranking(...)
```

**入口方式**：

- 命令行：`python run_backtest.py --stock 600036.SH --start 2024-01-01 --end 2025-12-31`
- Web 面板：`python server.py` 启动后在页面点击"单票回测"
- 代码调用：`BacktestCabinet(stock_code, strategy_id, ...).run(start, end)`

### 3.2 策略框架

#### 策略基类层次

```
BaseStrategy                          # 最基础的策略接口
  └── BaseImplementedStrategy         # 带通用工具的实现基类
        ├── Strategy00  长期持有一次买入
        ├── Strategy01  三周期共振波段
        ├── Strategy02  ...
        ├── ...
        └── Strategy09  箱体突破+RSI
```

#### BaseStrategy — 策略接口

```python
class BaseStrategy:
    def __init__(self, strategy_id):
        self.id = strategy_id
        self.positions = {}   # code -> qty
  
    def on_bar(self, kline):
        """核心钩子：每根K线调用一次，返回信号字典或 None"""
        raise NotImplementedError
  
    def update_position(self, code, qty):
        self.positions[code] = qty
```

#### BaseImplementedStrategy — 实现基类

在基类上增加了大量**通用工具方法**：

| 方法                                       | 功能                                            |
| ------------------------------------------ | ----------------------------------------------- |
| `update_holding_time(code)`              | 更新持仓时间（bar 计数）                        |
| `check_max_holding_time(code, max_bars)` | 检查是否超过最大持仓时间                        |
| `create_exit_signal(kline, qty, reason)` | 快速构建卖出信号                                |
| `_cfg(key, default)`                     | 从配置中读取策略参数                            |
| `_qty()`                                 | 根据配置计算下单数量（支持固定手数/资金百分比） |
| `set_backtest_context(**kwargs)`         | 回测时注入资金等上下文                          |

#### 信号字典格式

```python
{
    'strategy_id': '01',        # 策略编号
    'code': '600036.SH',        # 股票代码
    'dt': '2025-03-15 10:30',   # 时间戳
    'direction': 'BUY',         # BUY / SELL
    'price': 35.50,             # 价格
    'qty': 300,                 # 数量（手）
    'stop_loss': 34.40,         # 止损价（可选）
    'take_profit': 38.00,       # 止盈价（可选）
    'reason': '...'             # 原因说明（可选）
}
```

#### 策略示例 — Strategy01 三周期共振波段

```python
class Strategy01(BaseImplementedStrategy):
    """三周期共振波段策略"""
    def __init__(self):
        super().__init__("01", "三周期共振波段", trigger_timeframe="60min")
  
    def on_bar(self, kline):
        # 1. 积累历史 bar 数据
        # 2. 从 1min 重采样出日线和 60min
        # 3. 日线级别：MA10 趋势判断
        # 4. 60 分钟级别：MACD 金叉/死叉
        # 5. 量能：5日均量放大
        # 6. 三者共振时产生买入信号
        # 7. 持仓中追踪止损/止盈
```

### 3.3 技术指标库 Indicators

**文件**：`src/utils/indicators.py`

提供统一的技术指标计算封装，所有策略共用。

#### 支持的指标

| 指标         | 方法                                              | 参数                           |
| ------------ | ------------------------------------------------- | ------------------------------ |
| 简单移动均线 | `MA(series, window)`                            | series: 价格序列, window: 周期 |
| 指数移动均线 | `EMA(series, window)`                           | 同上                           |
| MACD         | `MACD(close, fast=12, slow=26, signal=9)`       | 返回 (DIF, DEA, MACD柱)        |
| RSI          | `RSI(close, window=14)`                         | 返回 RSI 值                    |
| KDJ          | `KDJ(high, low, close, n=9, m1=3, m2=3)`        | 返回 (K, D, J)                 |
| ATR          | `ATR(high, low, close, window=14)`              | 真实波幅                       |
| HHV/LLV      | `HHV(series, window)` / `LLV(series, window)` | 区间最高/最低                  |
| 布林带       | `BollingerBands(close, window=20, num_std=2)`   | 返回 (上轨, 中轨, 下轨)        |
| K线重采样    | `resample(df, rule)`                            | rule: '5min'/'15min'/'D'/'W'   |

#### 设计亮点

1. **自适应输入**：`_to_numeric_series()` 支持 Series / DataFrame / list 多种输入
2. **双接口命名**：同时支持 `MA()` 和 `ma()`，兼容通达信和 talib 风格
3. **灵活参数**：`window` / `period` / `timeperiod` 多种参数名都能识别

```python
# 以下调用方式等价
Indicators.MA(df['close'], 10)
Indicators.ma(df['close'], period=10)
Indicators.ma(df, timeperiod=10)  # 自动取 close 列
```

### 5.2 重点借鉴清单

#### ⭐⭐⭐ 优先级最高 — 直接借鉴

**1. 回测引擎框架**

你的 `backtest_b1.py` 和 `backtest_brick_pattern.py` 是脚本式回测，缺乏通用性。建议参考 `BacktestCabinet` 的设计：

- 统一的回测入口类
- 逐 bar 事件驱动
- 策略与引擎解耦（策略只需实现 `on_bar()`）
- T+1 结算 + 交易成本建模
- 标准化的回测报告输出

**2. 策略基类设计**

参考 `BaseStrategy` → `BaseImplementedStrategy` 的两层设计：

- 让 B1 选股、砖形图选股、OAMV 等策略都继承统一基类
- 统一信号格式 `{direction, price, qty, stop_loss, ...}`
- 统一的持仓管理、资金管理接口

**3. 技术指标统一封装**

你的指标计算散落在 `app/chart_indicators.py` 和各策略文件中，建议统一到一个 `Indicators` 工具类：

- 支持 Series/DataFrame 自适应输入
- 支持通达信风格和 Python 风格双命名
- 包含 K 线重采样功能

#### ⭐⭐ 优先级中 — 选择性借鉴

**4. 通达信公式编译器**

你的 `指标公式/` 目录下有大量通达信公式（oamv.txt, b1.txt, macd.txt 等），目前需要手动翻译成 Python。借鉴 `formula_compiler.py` 可以实现**自动编译**。

**5. 风控审核机制**

在回测中加入风控规则，让回测结果更接近实战：

- 止损幅度检查
- 仓位比例限制
- 日亏损熔断
- 连续亏损停仓

**6. 多数据源架构**

你的 `app/tushare_client.py` 只对接了 Tushare，可以参考金策的 Provider 模式，增加 AkShare（免费）、DuckDB（本地）等备选。

#### ⭐ 优先级低 — 了解思路

**7. Web Dashboard**

你目前用 PyQt 做桌面端，如果未来需要 Web 化可以参考。

**8. 策略进化（LLM 驱动）**

AI 自动生成和优化策略，是比较前沿的方向，目前不急于实现。

## 七、总结

**金策智算**是一个功能完善的 A 股量化系统，最值得学习的是它的**架构分层思想**——将策略生成、风控审核、执行清算三者完全解耦。虽然它用了"三省六部"的古代官制命名，但底层设计理念是现代量化系统的标准范式。

对于 trader 项目来说，**回测引擎框架 + 策略基类 + 技术指标库**这三块是最实际的借鉴点，可以显著提升项目的工程化水平和策略扩展能力。
