# 回测引擎、策略框架与策略进化改造设计方案

## 一、现状分析

### 当前项目已有能力

| 模块 | 现状 | 文件 |
|------|------|------|
| 交易模拟器 | 基础买卖/持仓/结算 | `core/trade/simulator.py` |
| 交易模型 | TradeRecord/HoldingPosition/SettlementResult | `core/models/trade.py` |
| 技术指标 | MA/EMA/SMA/KDJ/MACD/HHV/LLV 等 | `core/indicators/builtin.py` |
| 指标注册表 | FunctionSpec 统一注册 | `core/indicators/registry.py` |
| 表达式引擎 | 通达信公式解析+求值 | `core/expression/` |
| 选股引擎 | B1/砖形图评分 | `core/screening/` |
| 回测脚本 | 脚本式、硬编码、不可复用 | `backtest_b1.py` / `backtest_brick_pattern.py` |

### 核心问题

1. **回测引擎**：`backtest_b1.py` 和 `backtest_brick_pattern.py` 是独立脚本，指标计算、信号检测、收益统计全部内联，无法复用
2. **策略框架**：无统一策略基类，B1 和砖形图逻辑与回测代码强耦合
3. **策略进化**：完全缺失，无法自动生成/优化策略

## 三、模块一：回测引擎

### 3.1 设计目标

- 逐 bar 事件驱动，支持日线/分钟线多周期
- 策略与引擎完全解耦（策略只需实现 `on_bar()`）
- 内置 T+1 结算、交易成本建模
- 标准化回测报告（ROI、最大回撤、胜率、盈亏比、夏普比率）

### 3.2 目录结构


### 4.2 策略基类

```python
class BaseStrategy(ABC):
    """策略基类 — 所有策略必须继承"""

    def __init__(self, strategy_id: str, name: str):
        self.strategy_id = strategy_id
        self.name = name
        self.positions: dict[str, int] = {}    # symbol -> quantity
        self._context: StrategyContext | None = None

    @abstractmethod
    def on_bar(self, bar: pd.Series, context: StrategyContext) -> list[Signal]:
        """核心钩子：每根K线调用一次，返回信号列表"""

    def on_init(self, history: pd.DataFrame) -> None:
        """策略初始化（可选覆写），用于预热指标"""

    def on_trade(self, trade: TradeRecord) -> None:
        """成交回调（可选覆写），用于更新内部状态"""

    def update_position(self, symbol: str, quantity: int) -> None:
        """由引擎回调，同步持仓"""
```

```python
class ExpressionStrategy(BaseStrategy):
    def __init__(self, strategy_id: str, name: str, buy_expr: str, sell_expr: str):
        super().__init__(strategy_id, name)
        self.buy_condition = parse_expression(buy_expr)
        self.sell_condition = parse_expression(sell_expr)

    def on_bar(self, bar, context):
        if evaluate(self.buy_condition, context.history_bars, context.bar_index):
            return [Signal(direction="BUY", ...)]
        if evaluate(self.sell_condition, context.history_bars, context.bar_index):
            return [Signal(direction="SELL", ...)]
        return []
```

## 五、模块三：策略进化

### 5.1 设计目标

利用 LLM 能力，实现：
1. 根据自然语言描述自动生成策略代码（通达信公式或 Python）
2. 自动回测评估绩效
3. 根据回测结果反馈迭代优化
4. 多轮进化后保留最优策略

### 5.2 目录结构

```
core/evolution/
├── __init__.py
├── evolver.py           # StrategyEvolver 进化主控
├── generator.py         # StrategyGenerator LLM策略生成
├── evaluator.py         # StrategyEvaluator 自动评估
├── memory.py            # EvolutionMemory 进化记忆（历史绩效）
├── templates/           # 策略生成提示词模板
│   ├── generate.txt
│   └── optimize.txt
└── config.py            # EvolutionConfig
```

### 5.3 核心流程

```
用户描述策略意图
       ↓
StrategyGenerator（LLM）
  → 生成 ExpressionStrategy 的 buy_expr / sell_expr
  → 或生成 Python 策略类代码
       ↓
StrategyEvaluator
  → 自动注入 BacktestEngine 运行回测
  → 计算绩效指标
       ↓
EvolutionMemory 记录本轮结果
       ↓
达标？ → 是 → 保存策略
       → 否 → 将绩效反馈给 LLM → 迭代优化（最多 N 轮）
```

#### StrategyEvaluator

```python
class StrategyEvaluator:
    """策略自动评估器"""

    def __init__(self, engine: BacktestEngine, repository: StockRepository):
        self.engine = engine
        self.repo = repository

    def evaluate(self, strategy: BaseStrategy, stock_pool: list[str],
                 start_date: str, end_date: str) -> EvalResult:
        """在指定股票池和时间段上回测评估"""
        results = []
        for symbol in stock_pool:
            data = self.repo.get_daily_frame(symbol)
            result = self.engine.run(symbol, data)
            results.append(result)
        return self._aggregate(results)
```

#### StrategyEvolver — 进化主控

```python
class StrategyEvolver:
    """策略进化主控制器"""

    def __init__(self, generator: StrategyGenerator,
                 evaluator: StrategyEvaluator,
                 memory: EvolutionMemory,
                 config: EvolutionConfig):
        self.generator = generator
        self.evaluator = evaluator
        self.memory = memory
        self.config = config

    def evolve(self, intent: str, max_rounds: int = 5) -> EvolutionResult:
        """执行策略进化循环"""
        strategy = self.generator.generate(intent)

        for round_num in range(max_rounds):
            eval_result = self.evaluator.evaluate(strategy, ...)
            self.memory.record(round_num, strategy, eval_result)

            if self._meets_criteria(eval_result):
                return EvolutionResult(success=True, strategy=strategy, ...)

            strategy = self.generator.optimize(strategy, eval_result)

        return EvolutionResult(success=False, best=self.memory.get_best(), ...)
```

## 七、关键设计决策

### 7.1 为什么不直接照搬金策智算？

| 决策 | 原因 |
|------|------|
| 不用"三省六部"命名 | 项目体量不同，过度抽象增加认知负担 |
| 保留 PyQt 桌面端 | 现有交互体验成熟，不切换 Web |
| 复用现有 `core/expression/` | 已有完整的通达信公式解析+求值，无需重写 |
| 复用现有 `core/indicators/` | 指标体系已注册化，直接使用 |
| 策略进化用 ExpressionStrategy | 生成通达信公式比生成 Python 更安全可控 |

### 7.2 向后兼容

- 旧回测脚本 `backtest_b1.py` / `backtest_brick_pattern.py` 改为调用新引擎的入口，对外接口不变
- `core/trade/simulator.py` 保留不动，`SimBroker` 内部组合调用
- `core/screening/` 选股引擎保留不动，策略层可调用其评分函数

### 7.3 扩展性预留

- `BaseStrategy.on_bar()` 返回 `list[Signal]`，天然支持同一 bar 产生多个信号
- `BacktestEngine.run_portfolio()` 预留多票组合回测入口
- `StrategyRegistry` 支持动态注册/注销，为进化系统服务
- `RiskGuard` 规则可配置化，后续可扩展更多风控规则
