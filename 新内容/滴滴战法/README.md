## 核心内容

### 两套战法的分工

- **对称战法**：服务于 B 点，用于判断 **B1 的买卖区间**。
- **滴滴战法**：用于判断地铁的**上下车点**（买卖时机）。
- 此前 B 战只给了**下车滴（卖点）**，没给上车滴；本期给出**完整版**，补上**上车滴（买点）**。

### 滴滴战法核心规则

- **上车点 = 黄色K线**，"滴一下"买入。
- **下车点 = 绿色K线**，"滴一下"卖出。
- **一一对应**：一个黄色K线（上车）后面跟着一个对应的绿色K线（下车）。
- 地铁中间"暂停"的部分跟自己无关——**每个人有自己的上下车点**。

### 操作示例（以 VETA 为例）

1. 股价到达**对称战法的目标范围**内 → **黄色K线刷卡，滴一下上车（买入）**。
2. 到**绿色K线** → **滴一下下车（卖出）**。
3. 到下一站 B1 时 → 再**滴一下上车**。
4. 一路坐到绿色K线终点 → **滴一下下车**。
5. **不滴下车 = 坐过站**（该走没走）。

### 风险/纪律提醒

- 后面有新地铁到达时上车，**若发现坐错车 → 要止损下车**。
- **固执拿住不动 = 坐环线绕一圈**才能回到起点（套牢）。
- 看到其他乘客在下一站上车，**已与你无关**——他们的终点不是你最初的终点（不要追别人的车/不要乱换车）。
