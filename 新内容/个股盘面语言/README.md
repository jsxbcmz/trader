## 一句话概括

讲个股**分时盘面语言**如何定买卖：以 MACD 等动能 + 量比为依据，在分时图上用红/绿箭头给出底/顶买卖信号，并把盘面状态归为"上攻/下杀/震荡"三类，但必须结合日 K 与量比、切勿只看分时直接交易。

## 核心内容

### 前提：量比的局限

- 本期是"盘面语言回填量比"视频里埋的彩蛋。
- 因为**手机版量比只有当日数据**，所以个股盘面语言**仅对当日分时有效**。

### 第一：分时买卖时机的判断依据

- 主要依据 **MACD 等股价趋势/动能**来判断买卖点。
- **分时图绿色箭头** = 顶部区间**卖出**信号。
- **分时图红色箭头** = 底部区间**买入**信号。
- **价格线上标注的特殊标记** = **大资金进场**标志（注意：不一定是主力）。
- 关键纪律：**必须结合自己日 K 的买卖时点**来做分时交易，**切勿只看分时图直接买卖**。

### 第二：盘面语言（三种状态）

- 个股盘面语言显示在**分时图左上角**。
- 一共三种：**上攻 / 下杀 / 震荡**。
- 该语言会随盘面交易**实时变化**。

### 收尾

- 最后看一眼个股形态（仍位于左侧趋势），并切换到周线观察。

## 关键数据 / 实例

- 信号配色约定：**红箭头=底部买入、绿箭头=顶部卖出**。
- 盘面状态枚举：**上攻 / 下杀 / 震荡** 三态。
- 工具组合：**MACD 动能 + 量比 + 日 K 时点**，三者结合才有效。

## 要点总结

- 分时盘面语言只是"当日"参考，**核心仍是日 K + 量比**，分时用来择时、不能单独决策。
- 用红绿箭头快速看底/顶信号，用左上角"上攻/下杀/震荡"快速给个股当日定性。
- 看到大资金进场标记别盲目跟，**不一定是主力**。
