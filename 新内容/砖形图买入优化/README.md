讲一套**通用的"个股胜率战绩"回测代码框架**：以砖形图买点为样例，但买入条件可替换成自己的；代码自动计算该策略的复利、胜率、最大回撤等战绩并画到副图上。

## 核心内容

### 背景

- 本期更新的是**剩余部分的通用代码**，用"最哥版砖图"作为回测样例。
- 橙色部分 = 适配版砖图"六步执行"后的买点（核心是**黄线上方的三分之二处转强红**判断买点；这部分属充电内容，不展开）。

### 通用战绩代码三大块

代码主要分为三块：**买入条件 + 复利战绩信息 + 画图标记**。

1. **买入条件**（可替换）
   - 以砖图为例：**黄线上方 + 绿转强红**。
   - 可根据自己的条件适配买入。
   - 最终：把"确认买入"做成一个**判断有值的变量**，传给下游计算即可（即只要替换这个买入信号变量，整套战绩框架就能复用）。

2. **复利战绩**（持仓与收益统计规则）
   - 买入后：**脱离成本区 5% 以上 → 持仓 5 日**；否则**只持仓 1 日**，以此判断买入后的涨幅。
   - 根据总涨幅计算：
     - **最大回撤**
     - 买入策略的**连续做错次数**
     - 累计买入次数 / **每次买入后涨幅的均值**
     - 该策略至今的**复利及胜率详情**

3. **画图标记**
   - 把上述战绩信息**画图叠加到副图**中展示。
