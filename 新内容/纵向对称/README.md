## 一句话概括

这是一期基于"Z哥思想"的自研开源交易战法分享，讲解**纵向对称战法**——用对称翻折的几何方法，预测拐点出现时的低点建仓成本与高点清仓价格。

## 核心内容

本期是"对称战法"的迭代：
- **上一期（横向对称）**：左右对称，画微型反转判断 K 线是否出现拐点及拐的幅度。
- **本期（纵向对称）**：上下对称，用于预测拐点出现时的**低点建仓成本**或**高点清仓价格**。

前置操作：先把主图缩小、放宽视野判断个股趋势（左侧下跌 / 右侧上涨）。

纵向对称分为两个目标：

- **攻目标（进攻，用于右侧上涨行情）**
  - 右侧上涨出现**峰值点**时：计算「峰值点 ↔ 前一低点」的 **1/2 值**，作为峰值点转折后的**下一建仓成本点**。
  - 走势下跌到建仓成本点附近、出现**拐值点（低点）**时：以上一高点为对称轴，计算「上一高点 → 当前拐点」的差值，**向上翻折对称**，得到建仓后的**第一清仓目标价**。

- **退目标（防守，用于左侧下跌行情）**
  - 左侧下跌出现反弹峰值点时：预测反弹后的下跌点。
  - K 线到达下跌点附近出现拐值点时：给出本次下跌后的后续反弹上涨价格。

简化用法（无需判断行情）：

- **下跌出现拐值点**：后续上涨空间 ≈ 退目标 ~ 攻目标之间。
- **上涨出现峰值点**：后续下跌建仓空间 ≈ 退目标 ~ 攻目标之间（进入区间内建仓更具高盈亏比）。
- **短线 vs 长线**：短线看近目标，长线看远目标。

## 关键数据 / 实例（以"阿勉"个股为例）

- 峰值点 **93.55**，前一低点 **66.41** → 1/2 处建仓成本点 **79.98**。
- 下跌至建仓点附近出现拐值点 **76.85** → 以上一高点 93.55 为对称轴向上翻折 → 第一清仓目标价 **110.25**。
- 下跌拐值点时上涨空间示例：**85.20 ~ 110.25**；另一处 **80.99 ~ 94.46**。
- 短线目标 **94.46**，长线目标 **110.25**。
- 上涨峰值点对应的下跌建仓区间示例：**39.27 ~ 79.98**、**57.36 ~ 86.07**。

## 要点总结（UP主给出的 5 点）

1. 攻/退目标只在**峰值点或拐值点**才有意义。
2. 代表**低位上涨清仓空间**或**高位下跌建仓空间**。
3. 空间范围 = 一个指数/个股的"垃圾时间"与"干活时间"的判断依据。
4. 目标对应不同行情；不想细分就直接用区间。
5. 配合"纵向微型对称战法"找走势明显的票，攻退目标的预估才会越准。
