## 一句话概括

通过看**大盘分时图里黄线与白线的相对走势**，在开盘后约 17 分钟即可快速判断当日大盘的"晴雨表"——是大盘指数贡献股（白线）在动，还是小盘股（黄线）在动。

## 核心内容

### 基础定义

- **白线**：大盘指数贡献股（权重/大盘股）。
- **黄线**：小盘股。
- **判断时机**：开盘约 **17 分钟后**判断当日大盘晴雨表。

### 四种黄白线形态及其含义

1. **黄白线一起拉升** → "开门一起揽客"（多空齐涨，全面走强）。
   - 可回顾历史其他分时图找同类样例（见视频红框）。
2. **黄白线交错纠缠且向下、全熄火** → "一个都别想跑"（全面走弱）。
3. **黄线在白线上方，且黄线涨得比白线快** → 资金流向**小盘股进货**（小盘股活跃）。
4. **黄线在白线下方，且黄线开盘后向下、白线横盘** → **大盘股引护、小盘股出货**（权重护盘、小票被抛）。

### 看盘位置

- 大盘分时的"盘面语言/晴雨表结论"一般会体现在**分时图左上角**。

## 关键数据 / 实例

- **关键时间点**：开盘后约 **17 分钟**做判断。
- 没有给出具体数值公式，核心是**黄线（小盘）vs 白线（大盘权重）的相对位置与斜率**这一定性判断。

## 要点总结

- 大道至简：**黄线=小盘股、白线=大盘权重股**，看两条线的上下关系和拉升/下行节奏，就能快速给当日盘面"定性"。
- 四象限速记：
  - 同涨 → 全面进攻；同跌纠缠 → 全面熄火；
  - 黄上且更快 → 小盘进货；黄下+白横 → 权重护盘、小盘出货。
