# 砖形图选股评分系统改造方案

> 本方案完全基于 `111/1.md` 中记录的 3 种交易定式（N型起跳、横盘起跳、上升波段延续）及其成功案例 + 5 条风险过滤规则，提炼出一套**独立的、可量化的选股评分系统**。

---

## 一、设计思路

### 核心逻辑

```
信号触发（绿转红） → 模式识别（属于哪种定式） → 模式评分（符合度打分） → 风险过滤（扣分/一票否决） → 最终得分
```

整个系统分为 **4 层**：

| 层级 | 名称 | 作用 |
|------|------|------|
| **第 0 层** | 基础信号 | 砖形图绿转红，这是所有模式的共同前提 |
| **第 1 层** | 模式识别 | 判断当前信号属于哪种交易定式（可能同时命中多个） |
| **第 2 层** | 模式评分 | 针对每种定式，从案例中提炼的关键特征进行打分 |
| **第 3 层** | 风险过滤 | 5 条风险规则，扣分或一票否决 |

### 与现有系统的关系

本系统是**完全独立**的评分模块，不依赖现有的 `BrickBuyScorer`。可以作为一个新的 scorer 注册到回测引擎中，也可以独立用于选股筛选。

---

## 二、第 0 层：基础信号（入选门槛）

所有 3 种定式的共同前提，必须**全部满足**才能进入后续流程：

| 条件 | 公式/说明 | 来源 |
|------|----------|------|
| **砖形图绿转红** | 前一天砖形图下降（绿砖），今天砖形图上升（红砖）。即 `REF(AA,1)=0 AND AA=1`，其中 `AA = REF(砖型图,1) < 砖型图` | 3 种定式的共同核心 |
| **砖形图差值 > 0 且力度达标** | 信号日砖形图变化量 > 0，即 `砖型图 - REF(砖型图,1) > 0`；同时**今日变化量的绝对值 / 昨日变化量的绝对值 ≥ 0.5**，即 `ABS(砖型图 - REF(砖型图,1)) / ABS(REF(砖型图,1) - REF(砖型图,2)) >= 0.5`，确保翻红力度至少是前一天变化力度的一半，过滤掉微弱的噪音级翻红 | 基础有效性 |
| **短趋线 > 多空线** | 信号日当天白线（短趋线）在黄线（多空线）之上，即 `EMA(EMA(C,10),10) > (MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4`，确保中期趋势向好、多头排列 | 趋势环境要求 |

不满足以上**任一条件**的，直接跳过，不进入后续流程。

## 三、第 1 层：模式识别

根据信号日前后的价格形态，判断当前信号属于哪种交易定式。一个信号**可能同时命中多个模式**，取得分最高的模式作为最终模式。

### 模式 1：N型起跳

**定义**：最近时间内，股价以 N 型结构呈上升趋势，某天砖形图从绿砖变成了红砖。

**识别条件**：

| 特征 | 量化条件 | 说明 |
|------|---------|------|
| **存在前一波上涨** | 信号日前 30 个交易日内，存在一段连续红砖 ≥ 3 天的上涨波段 | N 型的第一笔上涨 |
| **存在回调** | 上涨波段结束后，出现连续绿砖 ≥ 2 天的回调 | N 型的回调笔 |
| **回调未破前低** | 回调阶段的最低价 > 前一波上涨起点的最低价 | 保持上升结构 |
| **信号日翻红** | 绿转红（第 0 层已满足） | N 型的第二笔上涨启动 |

**案例验证**：
- 002444（20251231）✅ 高符合度
- 002766（20251231）✅ 高符合度
- 600693（20241225）✅ 高符合度
- 000833（20241105）✅ 高符合度
- 002792（20251124）✅ 高符合度

### 模式 2：横盘起跳

**定义**：股价近几日横盘震荡，收盘价波动不大，某天收盘价涨幅突然加大，且砖形图绿砖变成红砖。

**识别条件**：

| 特征 | 量化条件 | 说明 |
|------|---------|------|
| **近期横盘** | 信号日前 N 日（5~12日）的收盘价振幅 < 5% | 收盘价波动不大 |
| **信号日突破** | 信号日涨幅 > 近 N 日平均涨跌幅的 2 倍 | 涨幅突然加大 |
| **信号日翻红** | 绿转红（第 0 层已满足） | 突破确认 |

**案例验证**：
- 600893（20260212）✅ 高符合度
- 600744（20260224）✅ 高符合度
- 600389（20250815）✅ 高符合度
- 600366（20250806）✅ 高符合度
- 600089（20250929）✅ 高符合度
- 601566（20251110）✅ 高符合度
- 002846（20250620）✅ 高符合度

### 模式 3：上升波段延续

**定义**：股价处于上涨阶段，没有形成 N 型结构和像样的回调，砖形图内原本是连续红砖然后出现了 1~2 个绿砖，紧接着某天又出现了红砖。

**识别条件**：

| 特征 | 量化条件 | 说明 |
|------|---------|------|
| **处于上涨趋势** | 信号日前 20 日收盘价线性回归斜率 > 0，且短趋线 > 多空线 | 确认上涨阶段 |
| **前期连续红砖** | 信号日前，存在连续红砖 ≥ 3 天的阶段 | 原本是连续红砖 |
| **短暂绿砖** | 连续红砖结束后，仅出现 1~2 个绿砖 | 没有像样的回调 |
| **信号日翻红** | 绿转红（第 0 层已满足） | 上涨延续 |

**案例验证**：
- 600843（20241023）✅ 高符合度
- 600410（20250811）✅ 高符合度
- 600363（20241029）✅ 高符合度
- 002402（20250916）✅ 高符合度

## 四、第 2 层：模式评分（满分 100 分）

每种模式有自己独立的评分维度，因为不同定式关注的核心特征不同。

### 模式 1 评分：N型起跳（满分 100 分）

从案例中提炼的关键成功因素：

| 维度 | 权重 | 评分项 | 评分规则 | 案例依据 |
|------|------|--------|---------|---------|
| **N型结构完整度** | 30分 | 回调幅度占前一波涨幅的比例 | 38%~62%（黄金分割区间）: 30分, 25%~38%或62%~75%: 20分, 其他: 10分 | N型结构越标准，成功率越高 |
| **KDJ 配合** | 25分 | J 值位置 | J < 20: 25分, J < 40: 18分, J < 55: 10分, J ≥ 55: 0分 | 文档明确提到"j值处于较低位置" |
| **B1买点配合** | 20分 | 信号日前一天是否处于 B1 买点附近 | 前一天 J 值为近期拐点且 < MIN_J: 20分, 前一天 J 值接近 MIN_J: 12分, 不满足: 0分 | 文档明确提到"最好是信号日的前一天处于B1买点" |
| **翻红力度** | 15分 | 砖形图变化量 | 变化量 ≥ 前绿砖下降量: 15分, ≥ 70%: 10分, ≥ 50%: 5分, < 50%: 0分 | 翻红力度越大，反转越可靠 |
| **趋势支撑** | 10分 | 收盘价与短趋线/多空线的关系 | 收盘价在短趋线附近（±3%）且短趋线 > 多空线: 10分, 仅短趋线 > 多空线: 5分, 其他: 0分 | 趋势向好提供安全边际 |

### 模式 2 评分：横盘起跳（满分 100 分）

从案例中提炼的关键成功因素：

| 维度 | 权重 | 评分项 | 评分规则 | 案例依据 |
|------|------|--------|---------|---------|
| **横盘质量** | 30分 | 横盘期间收盘价标准差 / 均价 | < 1.5%: 30分, < 2.5%: 22分, < 3.5%: 14分, ≥ 3.5%: 5分 | 波动越小，蓄势越充分 |
| **突破力度** | 25分 | 信号日涨幅 / 横盘期间平均日涨跌幅绝对值 | ≥ 3倍: 25分, ≥ 2倍: 18分, ≥ 1.5倍: 10分, < 1.5倍: 3分 | 突破要明显超出横盘波动 |
| **横盘时长** | 20分 | 横盘持续的交易日数 | 5~8天: 20分, 3~4天: 14分, 9~12天: 10分, > 12天: 0分（触发风险规则3） | 适度横盘最佳，过长则资金离场 |
| **量价配合** | 15分 | 信号日量比（vs 横盘期间均量） | 1.3~2.0: 15分, 1.0~1.3: 10分, 2.0~3.0: 7分, < 1.0或 > 3.0: 3分 | 温和放量突破最健康 |
| **趋势支撑** | 10分 | 短趋线与多空线关系 | 短趋线 > 多空线且差距不收窄: 10分, 仅短趋线 > 多空线: 5分, 其他: 0分 | 趋势向好提供安全边际 |

### 模式 3 评分：上升波段延续（满分 100 分）

从案例中提炼的关键成功因素：

| 维度 | 权重 | 评分项 | 评分规则 | 案例依据 |
|------|------|--------|---------|---------|
| **上涨趋势强度** | 30分 | 前期连续红砖天数 + 20日趋势斜率 | 连续红砖 ≥ 5天且斜率 > 0.5%: 30分, ≥ 3天且斜率 > 0.2%: 22分, 其他: 10分 | 上涨趋势越强，延续概率越高 |
| **绿砖短暂性** | 25分 | 中断的绿砖天数 | 1天: 25分, 2天: 18分, 3天: 8分, > 3天: 0分（不再是"延续"） | 文档明确说"1/2个绿砖" |
| **绿砖缩量** | 20分 | 绿砖日成交量 vs 前期红砖日均量 | 绿砖量 < 红砖均量的 60%: 20分, < 80%: 14分, < 100%: 8分, ≥ 100%: 2分 | 缩量回调说明惜售，放量回调说明抛压 |
| **翻红力度** | 15分 | 信号日砖形图变化量 vs 绿砖下降量 | ≥ 绿砖总下降量: 15分, ≥ 70%: 10分, ≥ 50%: 5分, < 50%: 0分 | 翻红要能覆盖绿砖的下降 |
| **价格位置** | 10分 | 信号日收盘价 vs 前期红砖最高收盘价 | 差距 < 2%: 10分, < 5%: 7分, < 8%: 4分, ≥ 8%: 0分 | 越接近前高，延续动能越强 |

## 五、第 3 层：风险过滤（扣分 / 一票否决）

直接来源于文档中的 5 条风险过滤规则。

### 一票否决型（命中即排除，无论评分多高）

| 规则 | 条件 | 处理 |
|------|------|------|
| **规则 1：近期一字板跌停** | 信号日前 10 个交易日内，存在一字板跌停（跌幅 ≤ -9.5% 且 开盘价 = 最低价） | **直接排除** |
| **规则 4：近期放量大阴线** | 信号日前 10 个交易日内，存在量比 > 1.5 且跌幅 > 3% 的交易日 | **直接排除**（但有豁免条件，见下方） |

**规则 4 的豁免条件**：如果放量大阴线之后、信号日之前，股价已经放量突破了大阴线当天的最高价，则忽略本规则。
> 案例：002766，放量绿色交易柱子 20251217，股价超过日 20251222，信号日 20251231 → 豁免

### 扣分型（命中后扣分，扣到阈值以下则排除）

| 规则 | 条件 | 扣分 | 阈值 |
|------|------|------|------|
| **规则 2：黄白线差距收窄** | 信号日当天（短趋线 - 多空线）< 前一日（短趋线 - 多空线） | **-15 分** | 扣后 < 60 分则排除 |
| **规则 3：横盘时间过长** | 横盘起跳模式下，横盘时间 > 12 个交易日 | **-20 分**（实际上横盘评分维度已给 0 分，这里额外再扣） | 扣后 < 60 分则排除 |
| **规则 5：连续未缩量绿砖** | 信号日前 15 个交易日内，存在连续 ≥ 3 天的绿砖且平均量比 > 0.8 | **-15 分** | 扣后 < 60 分则排除 |

### 风险规则优先级

```
🔴 规则1（一字板跌停）  → 直接排除
🔴 规则4（放量大阴线）  → 直接排除（除非满足豁免条件）
🟡 规则3（横盘过长）    → -20 分
🟡 规则5（未缩量绿砖）  → -15 分
🟢 规则2（黄白线收窄）  → -15 分
```

---

## 六、最终得分与信号分级

### 计算公式

```
最终得分 = 模式评分（100分制） - 风险扣分
```

### 信号分级

| 得分区间 | 等级 | 建议 |
|---------|------|------|
| **80~100** | ⭐⭐⭐ S 级 | 高度符合定式，强烈关注 |
| **65~79** | ⭐⭐ A 级 | 较好符合定式，值得关注 |
| **50~64** | ⭐ B 级 | 部分符合，谨慎观望 |
| **< 50** | 无效 | 不建议参与 |

### 多模式命中时的处理

如果一个信号同时命中多个模式（如既像 N 型起跳又像横盘起跳），取**得分最高的模式**作为最终结果，并在输出中标注所有命中的模式。

## 八、实现计划

### 模块结构

```
core/scoring/
├── __init__.py
├── models.py              # 数据模型（评分结果、模式枚举等）
├── base_signal.py         # 第0层：基础信号检测（绿转红）
├── pattern_detector.py    # 第1层：模式识别（N型/横盘/延续）
├── pattern_scorer.py      # 第2层：模式评分（3种模式各自的评分逻辑）
├── risk_filter.py         # 第3层：风险过滤（5条规则）
└── engine.py              # 总引擎：串联 0→1→2→3 层，输出最终结果
```

### 依赖的指标计算

| 指标 | 计算方式 | 用途 |
|------|---------|------|
| **砖形图** | 现有公式（VAR1A~VAR6A） | 绿转红判断、红/绿砖识别 |
| **短趋线** | EMA(EMA(C, 10), 10) | 趋势判断、价格位置 |
| **多空线** | (MA(C,14) + MA(C,28) + MA(C,57) + MA(C,114)) / 4 | 趋势判断 |
| **KDJ** | 标准 KDJ 公式（RSV→K→D→J） | N型起跳的 J 值评分 |
| **MIN_J** | 多周期 J 值拐点均值 | N型起跳的 B1 买点判断 |

### 开发步骤

1. **定义数据模型**：模式枚举、评分结果结构
2. **实现基础信号检测**：绿转红判断
3. **实现 3 种模式识别器**：分别量化 N 型、横盘、延续的识别条件
4. **实现 3 种模式评分器**：分别实现各维度的评分逻辑
5. **实现 5 条风险过滤规则**：一票否决 + 扣分
6. **实现总引擎**：串联所有层级
7. **用文档中的案例做回归验证**：确保已知的高符合度案例能拿到高分

## 十、后续迭代方向

1. **阈值校准**：用更多案例（包括失败案例）校准各评分维度的阈值
2. **权重优化**：通过回测结果反馈，调整各维度的权重分配
3. **新模式扩展**：随着交易经验积累，可以新增更多定式模式
4. **板块适配**：当前方案以主板（10%涨跌幅）为基准，后续可扩展创业板/科创板的阈值
5. **与回测系统集成**：将本评分系统注册为新的 `buy_scorer`，接入现有回测引擎进行策略验证
