## 一、怎么看K线？关键K线识别规则

### 核心认知

> 📌 **【关键K / 关键K线】定义**：100根K线中真正有意义的只有3~5根，这些能够决定后续走势方向的K线就是关键K。关键K是主力发出的信号，有两大意义：**趋势反转**和**走势衰竭**。识别要素：①位置在大哥线（均线）附近 ②成交量够大（"一览众山小"）。形态对但量不够 = 假信号。

- 100 根 K 线中真正有意义的只有 **3~5 根**，其余都是垃圾时间
- **关键K** = 能够决定后续走势方向的 K 线，是主力发出的信号
- 关键K 有两大意义：**趋势反转** 和 **走势衰竭**

### 六种趋势反转类型

| 序号 | 反转类型 | 形象比喻 |
|------|----------|----------|
| 1 | 下跌 → 上涨 | V 型反转 |
| 2 | 下跌 → 横盘 | 紧急刹车 |
| 3 | 横盘 → 上涨 | 平地惊雷，大哥明牌入场 |
| 4 | 上涨 → 下跌 | A 杀反转 |
| 5 | 上涨 → 横盘 | 高位震荡 |
| 6 | 横盘 → 下跌 | 丢盔弃甲，防线失守 |

### 识别关键K的两大要素

**要素一：位置** — 必须出现在大哥线（均线）附近，突破或跌破大哥线且放量

**要素二：成交量** — 量必须够大，最好"一览众山小"（比前面所有 K 线的量都大）

**铁律**：形态对但量不够 = 假信号，千万别追

### 主力什么时候进场？大资金入场信号（三条件同时满足）

1. **关键位置**：大哥线附近
2. **放量**：比前高更大
3. **大阳线**：实体够长，涨停板最好

→ 出现后画两条线（最高价 + 最低价），后续股价在此区间运行，区间内不动

### 主力什么时候出货？大资金离场信号

> 📌 **【放量阴线】定义**：加速上涨之后出现的高位阴线，且成交量比前面阳线还大。这是主导资金出货的信号，对应 S1 卖出信号。放量阴线第一时间卖，卖错也要卖。

- **加速之后的高位放量阴线，量比前面阳线还大** = 真正的出货信号（S1）
- 连续上涨中的放量大阳线只是加速拉升，不是关键K

### 涨不动了怎么看？走势衰竭信号

- 上涨过程中出现 **缩量小阳线创新高** = 买盘枯竭
- 跌破这根小阳线的最低价 → 容易熄火回调

### 实战三步法

1. **找关键K**：找放量最大的位置
2. **画线**：画出关键K的高点和低点两条水平线
3. **观察**：区间内不动 → 向上突破加仓 → 向下跌破止损

### 看图四问

1. 大哥在哪？
2. 大哥的成本在哪？
3. 大哥什么时候入场？
4. 大哥什么时候离场？

## 二、底部放量大阳线是什么意思？底部暴力K线识别与操作规则

> **常见问题**：底部突然放量拉涨停是什么信号？跌了很久突然大阳线要不要追？底部暴力K线怎么买？

### 定义

> 📌 **【底部暴力K线】定义**：一个票跌了很久后突然出现的放量大阳线，往往是中线波段的起始点。四个识别条件：①位置对（绝对/相对底部）②够突兀（莫名其妙）③量够大（实体大阳+倍量）④让你害怕（散户恐慌时刻）。可能是两三根K线组成的组合。

底部暴力K线 = 一个票跌了很久后突然出现的放量大阳线，往往是中线波段的起始点。

### 两个前提基础

1. **关键K**：能分辨哪根K线有意义、哪根是噪音
2. **倍量柱**：成交量突然翻倍以上。只关注三种量：倍量、天量、缩量，其他一般放量不用看

### 三种分类

| 类型 | 趋势变化 | 操作建议 |
|------|----------|----------|
| **大暴力** | 下跌→横盘 / 横盘→上涨 | ✅ 重点操作 |
| **小暴力** | 上涨趋势中回调后再启动 | ✅ 重点操作 |
| **趋势扭转** | 暴跌中突然止跌 | ❌ 只看不动手（可能只是反弹） |

### 四个识别条件（全占 = 空谷幽兰级别机会）

| 条件 | 关键词 | 说明 |
|------|--------|------|
| ① 位置对 | 绝对底部 / 相对底部 | 长期下跌最低区域 或 上涨回调低位 |
| ② 够突兀 | 莫名其妙 | 让所有人看不懂，越突兀越好 |
| ③ 量够大 | 又粗又大 | 实体大阳 + 倍量，无长上影线 |
| ④ 让你害怕 | 恐慌时刻 | 出现在散户恐慌离场的时间点 |

**为什么让你害怕的时候反而是好机会**：散户恐慌离场 → 盘面变轻 → 主力稍微一买价格就蹭蹭涨

### 操作方法

- **推荐**：等 B1 进场（回调到相对低位再入场，成本更低、止损更小）
- **激进**：次日直接追，止损位 = 买入当天K线最低点，跌破就走

### 注意

- 底部暴力K线可能是两三根组成的组合，不一定是单根
- 用波段思维对待，不是短线追涨停的工具

## 三、成交量怎么看？量价关系分析规则

> **常见问题**：放量代表什么？缩量说明什么？倍量柱是什么意思？天量要不要跑？量价齐升是什么？怎么通过成交量判断主力动向？

### 底层逻辑

- 收盘价 = 多空博弈的最终结果
- 盘中震荡别管，**等收盘前再判断**

### 成交量四个层级

> 📌 **【倍量 / 倍量柱】定义**：成交量至少是前一天的两倍 = 大哥来了，增量资金进场。是判断主力资金介入的核心信号。不追倍量柱本身，等回调缩量再进场。
>
> 📌 **【天量】定义**：倍量之后再倍量，成交量达到极端水平。警惕信号！可能是加速赶顶或主力坚决出货，该放飞就放飞。

| 层级 | 定义 | 意义 |
|------|------|------|
| **一般放量** | 比昨天稍高 | 不大，正常波动 |
| **大幅放量** | 介于一般和倍量之间 | 配合阳线通常是好事 |
| **倍量** ⭐ | 至少是昨天的两倍 | 大哥来了，增量资金进场 |
| **天量** | 倍量之后再倍量 | 警惕！可能加速赶顶或坚决出货 |

### 量价配合四种情况

| 类型 | 表现 | 含义 |
|------|------|------|
| **量价齐升** ✅（📌 价涨量涨，最健康的上涨形态） | 价涨量涨 | 最健康的上涨形态，真金白银进场 |
| **平量** | 量跟前几天差不多 | 趋势大概率延续 |
| **缩量** ⭐（📌 量明显萎缩，只在上涨回调中有意义：说明没人卖，后面大概率继续涨。下跌中的缩量无意义） | 量明显萎缩 | **只在上涨回调中有意义**（见下文） |
| **地量**（📌 缩到这一波最低的成交量，配合N型结构+买入信号 = 最佳买点） | 缩到这一波最低 | 配合N型结构+买入信号 = 最佳买点 |

### 缩量的关键规则

- **上涨回调中的缩量（长阴短柱 / 异动缩量）**：说明没人卖，后面大概率继续涨
- **下跌过程中的缩量**：无意义，下跌不需要量，不用研究

### 实战四大原则

1. **不追倍量柱**：大哥来了但不知道吃饱没，等回调缩量再进场
2. **警惕天量**：倍量之后再倍量，该放飞就放飞
3. **算面积辨震仓 vs 出货**：拉升阶段阳线成交量之和 vs 杀跌阶段阴线成交量之和，阴线量远小于阳线量 = 震仓洗盘
4. **缩量涨停要小心**：主力高度控盘，后续完全取决于主力心情，风险大

## 四、怎么识别假的买入信号？30+30 黄金法则（识别假B1）

> **常见问题**：什么是假B1？为什么买入信号出来了还是跌？30+30法则怎么用？涨幅和换手率怎么判断？

### 核心问题

> 📌 **【30+30法则 / 30+30黄金法则】定义**：识别假B1的过滤器。第一个30 = 建仓波涨幅不超过30%（超过40%打问号）；第二个30 = 建仓波累计换手率不超过30%（超过40%一律当废掉的B1处理）。两个条件同时用于筛选，是选B1的必过滤器。

底部放量拉升看着像标准B1，冲进去后股价再也没起来 → 那不是建仓，是拉高出货。

### 第一个30：涨幅30%

- 建仓波从启动点到最高点的涨幅，正态分布峰值在 **30%** 左右
- 高概率区间：**25%~35%**
- **超过40%要打问号**

### 第二个30：累计换手率30%

- 建仓波中几根放量大阳线的换手率**累加**（不是单根）
- 正态分布峰值也在 **30%** 左右
- **超过40%一律当废掉的B1处理**
- 换手率90%+说明筹码已换了好几轮 = 底下捡筹码拉上去全出掉了

### 辅助判断规则

- **建仓阶段不喜欢跳空**：跳空大概率是进攻不是建仓，进攻完容易熄火
- **好的量价关系**：底部放大量、高位缩量；反过来高位放大量 = 大概率出货
- **做你看得懂的图**：看不懂的票不赚那个钱

### 快速筛选口诀

> **涨幅30，换手30** — 两个30%法则，选B1必过滤器

## 五、主力洗盘怎么识别？击穿对手盘识别规则（长阴短柱）

> **常见问题**：什么是击穿对手盘？为什么一卖就涨？长阴短柱是什么意思？缩量下跌是洗盘还是出货？放量暴跌要不要跑？斩杀线是什么？

### 什么是击穿对手盘

> 📌 **【击穿对手盘】定义**：主力故意打压股价，精准击穿散户公认的止损位，迫使散户恐慌卖出，从而低价收集筹码的行为。核心识别密码是"长阴短柱"（缩量大阴线）。前提是主力高度控盘（缩量新高 + 股东户数大幅减少）。

主力故意打压股价，精准击穿散户公认的止损位，迫使散户恐慌卖出，从而低价收集筹码。

**你一卖就涨 — 因为你就是那个被击穿的对手盘。**

### 前提条件：主力高度控盘

**判断维度一：盘面 — 缩量新高**（📌 **缩量新高** = 股价创新高但成交量萎缩，说明主力高度控盘、锁仓不动）
- 股价创新高但成交量萎缩 → 主力锁仓不动，外面散户手里没多少筹码

**判断维度二：数据 — 股东户数大幅减少**
- F10 查看股东研究，一个季度内股东人数减少 28%~30% → 筹码从散户集中到主力

两者印证 = 确认高度控盘

### 主力为什么要击穿

- 建仓拉升过程中积累了大量跟风盘（获利盘）
- 获利盘 = 拉升路上的绊脚石
- 主力必须在主升浪前清洗不坚定筹码

### 核心识别密码：长阴短柱

> 📌 **【长阴短柱】定义**：大阴线（跌幅大甚至跌停）对应的成交量非常小。说明主力用很少筹码左手倒右手把价格打下来，是在画图吓唬散户。长阴短柱 = 洗盘信号，应拿住筹码不卖。

- **定义**：大阴线（跌幅大甚至跌停）对应的成交量非常小
- **含义**：主力用很少筹码左手倒右手把价格打下来，是在画图吓唬你
- **口诀**：**缩量下跌 = 大概率洗盘；放量暴跌 = 斩杀，必须跑**

### 综合判断方法

1. 前期有倍量柱（主力资金介入深）
2. 有关键K线异动
3. 回调过程中全是缩量甚至地量
4. 即使跌破止损位、跌穿均线，只要缩量就多留心眼

### 止损策略升级

对高度控盘+正在洗盘的票，不能用短线止损法，要找主力成本线作为防守线：
- 前期主力建仓时那根放量关键K线
- 底部倍量柱的最低点
- N型结构的起涨点
- 给 **15%~20%** 的波段止损空间

### 斩杀线（必须跑的情况）

> 📌 **【斩杀线】定义**：下跌过程中突然放出巨量 + 巨大阴线 + 连续放量下跌。通常是基本面重大恶化，主力也在逃命。与"长阴短柱"（洗盘）的本质区别是：斩杀线是**放量**暴跌。第一时间止损，不要有任何幻想。

- 下跌过程中突然**放出巨量 + 巨大阴线 + 连续放量下跌**
- 通常是基本面重大恶化，主力也在逃命
- **第一时间止损，不要有任何幻想**

### 区分速查

| 特征 | 击穿（洗盘） | 斩杀（出货） |
|------|-------------|-------------|
| 成交量 | 缩量 | 放量 |
| K线形态 | 长阴短柱 | 放量大阴线 |
| 本质 | 主力吓唬你收筹码 | 主力真的在跑 |
| 操作 | 拿住筹码，跟大哥共患难 | 立即止损，不幻想 |

## 六、股票拉不起来了怎么判断？熄火判断规则

- 反复放量拉起又下来，但始终不加速

> **它不能墨迹，墨迹就下来了。**
