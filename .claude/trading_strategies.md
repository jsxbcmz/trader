## 一、双线战法怎么用？白线黄线金叉死叉操作体系（少妇战法 Pro 版）

### 大前提

所有双线战法的逻辑都建立在 **N型结构** 基础上。趋势向下时不适用。

> 📌 **【N型结构】定义**：上涨 → 回调 → 再上涨，高低点不断抬高的上升趋势形态。形状类似字母"N"。是所有战法的基础前提，趋势向下（低点不断降低）时不适用。

### 两条线的定义

> 📌 **【白线】定义**：短期趋势线，比喻为"牵牛绳"。只要股价不跌破白线，就死死拽住不放。跌破白线 = 减仓信号。
>
> 📌 **【黄线】定义**：主力资金成本区，比喻为"大哥线"。是主力极限洗盘的最后防线。黄线之下不看、不做，只做黄线之上的生意。

| 线 | 含义 | 比喻 |
|----|------|------|
| **白线** | 短期趋势线 | 牵牛绳 — 只要不破就死死拽住 |
| **黄线** | 主力资金成本区 | 大哥线 — 主力极限洗盘的最后防线 |

### 什么时候可以买入？最核心逻辑

> **右侧交易，只做白线金叉黄线的票。**

> 📌 **【金叉】定义**：白线从下方穿越到黄线上方 = 大哥带着钱进场了，可以进场做多。
>
> 📌 **【死叉】定义**：白线从上方跌落到黄线下方 = 大哥关门歇业了，必须离场。死叉是最后的离场哨声。

| 状态 | 含义 | 操作 |
|------|------|------|
| 白线在黄线上方（金叉） | 大哥带着钱进场了 | ✅ 可以进场 |
| 白线在黄线下方（死叉） | 大哥关门歇业了 | ❌ 不看、不做 |

**铁律**：黄线之下不看，只做黄线之上的生意。即使涨得再欢，黄线之下也只是反弹。

### 四种玩法

#### 玩法一：无脑跟随法（最简单）

> 📌 **【B1买点】定义**：右侧交易的标准买入信号。在金叉状态下，股价回调到合适位置后出现的第一个买入确认点。是波段和双线战法中最核心的入场信号。

- 白线金叉黄线 → 等 B1 买点入场
- 更懒版本：金叉进，死叉出
- 优点：不踏空、不卖飞
- 缺点：掐头去尾，横盘震荡容易被打脸

#### 玩法二：回调到哪里可以接？区间买入法 ⭐（重点推荐）

> 📌 **【白黄线区间】定义**：白线和黄线之间的价格区域。异动拉升后缩量回调掉进此区间 = 容错率极高的买入区，是大哥的护盘区，可分批建仓。

- **白线和黄线之间的区域** = 容错率极高的买入区
- 异动拉升后缩量回调，掉进白黄线之间就可以分批建仓
- 买点范围大大拓宽，都是大哥的护盘区
- ⚠️ 白黄线张口特别大时别买（浮亏太大）
- ⚠️ 只适用于有异动之后的票，死气沉沉横盘的不适用

#### 玩法三：搏击线 — 主升浪启动前的极限买点（胜率极高 🎯）

> 📌 **【搏击线】定义**：主升浪启动前的极限买点。在放量金叉上涨趋势中，股价突然缩量回调踩到黄线附近甚至瞬间跌破，第二天又拉回来。本质是主力拉升前最后一次凶狠震仓，是条件更苛刻但胜率极高的 B1 买点。

触发条件（苛刻但价值极大）：
1. 放量金叉形成的上涨趋势中
2. 股价突然缩量回调
3. 直接踩到黄线附近甚至盘中瞬间跌破
4. 第二天又拉回来

本质：主力拉升前最后一次凶狠震仓，往往对应主升浪启动点。是条件更苛刻的 B1 买点。

#### 玩法四：逆人性极限买点（适合大票）

- 适用：队长、宁王等大票
- 条件：双线死叉较多 + N型结构没破 + 筹码值大负值
- 必须设好止损，只输一根K线就走

### 什么时候必须卖出？离场铁律

> 📌 **【S1卖出信号】定义**：加速上涨之后出现的高位放量阴线，量比前面阳线还大 = 主导资金出货信号，必须果断减仓。详见 `trading_rules.md` 关键K线章节。

> **白线死叉黄线 = 最后的离场哨声，不管亏了赚了，走错也要走。**

### 完美循环操作流程

```
1. 入场：B1 买点 或 金叉入场
   ↓
2. 持股：横盘或温和上涨 → 拿住不动
   ↓
3. 加仓：股价回调到白黄线区间 → 加仓（可打满仓位）
   ↓
4. 放飞（📌 放飞 = 股价加速上涨远离成本区时，逐步卖出锁定利润）：加速拉升脱离成本区 → 享受泡沫
   ↓
5. 减仓：跌破白线（牵牛绳）→ 减仓卖出
   ↓
6. 观察：卖出后继续观察
   ↓
7. 回补：再次回到白黄区间 或 出现 B1 → 接回
   ↓
   重新开始循环
```

## 二、波段怎么做？波段操作完整流程（七步法）

> **常见问题**：波段操作的步骤是什么？怎么用周线选股日线买入？N型结构是什么？波段止损怎么设？放量阴线要不要卖？

### 三个基本功

**基本功一：N型结构**（📌 定义见上方双线战法章节）
- 上涨 → 回调 → 再上涨，高低点不断抬高 = 上涨趋势
- 买完回调不要慌，股票都是N型走的

**基本功二：止损**
- 控制回撤三招：快速止损、果断放飞、仓位管理
- 止损是成本，买的同时止损价就要定好

**基本功三：周线格局**
- 日线看不明白切到周线，周线是大资金用真金白银画出来的
- **周线选股，日线买入。顺大势，逆小势。**

### 七步操作框架

**第一步：周线找N型结构**
- 周线上找白线之上的N型结构，均线多头排列，趋势向上
- 用这个条件筛，5000多个票立马剩1000个

**第二步：找大资金布局的标的**
- 日线上有异动，底部有放量涨停 = 主力已进场
- 图形永远走在消息之前

**第三步：周线均线关系判断入场位置**
- 周线均线都向上发散 = 趋势没完
- 回到日线找 B1 信号入场

**第四步：日线B1匹配进场条件**
- 周线回调时日线出现 B1 = 入场点
- 周线不破位，日线的B1只是多几天，不影响大趋势

**第五步：设好止损**
- 周线B1进的 → 按周线位置设止损（不要被日线波动吓出来）
- 日线B1进的 → 在日线上设止损
- 原则：看大做小，买大指大，买小指小

**第六步：日线级别做放飞和卖出**
- 空头思维：敢涨就敢砸，先锁利润
- 出现 S1 放量阴线果断减仓
- 抢在调整之前卖，你是在砸它，不是被它砸出来

**第七步：趋势没改变就盯住不放**
- 止损出来不代表票结束了
- 跌下来出现新的B1照样追着买回去
- 一直到周线破位为止

### 三种波段方式

| 方式 | 说明 | 推荐度 |
|------|------|--------|
| **左侧低估** | 跌到地板分批买，等起来 | 适合大资金老手 |
| **超跌反弹** | 技术性反弹，高度和持续性不确定 | ❌ 不推荐 |
| **多头控盘** ⭐ | 周线均线多头排列，趋势已确立，找B1入场 | ✅ 全力以赴做 |

### 每日三问（避免迷糊）

| 问题 | 目的 |
|------|------|
| 我这个票做的是波段还是超短线？ | 波段别被日线吓到；超短线别恋战 |
| 我做的是左侧还是右侧？ | 左侧别在意每天波动；右侧该止损就止损 |
| 今天有没有放量阴线出来？ | **放量阴线第一时间卖，卖错也要卖** |

> ⚠️ 放量阴线意味着主导资金在出货。做错九次没关系，有一次没走，少则一两个月白干，多则一整轮牛市白干。

## 三、超短线怎么做？超短线买卖规则与纪律（砖形图红包翠战法）

> **常见问题**：超短线的买卖规则是什么？砖形图红包翠怎么用？超短线仓位怎么管理？超短线持仓几天？高开多少不追？超短线止盈止损怎么设？散户为什么亏钱？

### 风险警告（三句前言）

1. **不鼓励所有人玩超短线**，大部分人只会死得更快
2. 四种结局中只有 **1/4 概率**能赚钱（顺逆都扛住+懂得见好就收）
3. 硬性约束：只适合 **100万以下小资金**、不用杠杆、不用输不起的钱、不杀红眼、**不补仓**

### 核心逻辑

> **寻找转折点的爆发力** — 找蹲下去之后猛地弹起来的票

不是追涨停、不是突破战法、不是强者恒强。赚的是调整/横盘结束后动能反转向上的那一下子。

### 三大原则

1. **专注单一策略**：就用一种方法，不混入波段思维
2. **无脑执行策略**：到位置就买，出信号就走，不动脑子不纠结
3. **速战速决**：一把就开，不拖不等不幻想

### 六条执行规则

| 规则 | 内容 | 关键数值 |
|------|------|----------|
| ① 黄线之上 | 股价必须在黄线之上 | 弱势票不碰 |
| ② 红绿柱比（📌 砖形图中红柱代表上涨动能，绿柱代表下跌动能，红柱≥绿柱2/3说明多头力量足够） | 红柱长度 ≥ 绿柱的 2/3 | 不够2/3不做 |
| ③ 买入时机 | 当日尾盘买 或 次日早盘买 | 高开 > 4% 不追 |
| ④ 仓位分半 | 资金对半分，每票一个仓位 | 最多同时持有2票 |
| ⑤ 止损位 | 买入那根K线的最低价 | 2个交易日不拉就走 |
| ⑥ 止盈周期 | 脱离成本区 5% 以上 | 持仓最多 4~6 天 |

### 心法四句口诀

| 口诀 | 核心含义 |
|------|----------|
| **我要赚钱，给多少拿多少，积少成多** | 半仓赚3%就是总仓位1.5%，连续赚十次复利可观 |
| **不给就走** | 没爆发走，爆发了也走，买就是为了走 |
| **永不完美** | 踏空是策略的一部分，用踏空换重仓不被套、控制回撤、还有钱做下一笔 |
| **下一个会更好** | A股几千只票每天都有新机会，不在一棵树上吊死 |

### 收益预期

| 场景 | 预期 |
|------|------|
| 单次操作 | 3%~5%，偶尔赶上涨停板 |
| 行情好的月份 | 20%~30% |
| 行情差的月份 | 控制亏损 < 10% |
| 一年下来 | 小资金翻几倍可期 |

### 散户为什么亏钱？六大常见交易误区

| 误区 | 表现 |
|------|------|
| 没有依据就入场 | 听消息就冲，路过就买 |
| 不预设离场点 | 涨了不知道卖，跌了不知道割 |
| 强者恒强谁强追谁 | 涨四个点追进去，套在山顶 |
| 满仓蛮干 | 一笔全打进一个票，一个跌停直接崩 |
| 套住就不动 | 想做短线赚一把，被套五个点就装死 |
| 不停追热点 | 每个高点被套一波，解完套又追下一个 |

> **超短线的世界里，没有完美，只有纪律。**
