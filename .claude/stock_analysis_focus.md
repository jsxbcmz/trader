# 个股分析侧重点

> 分析股票时，Claude 必须先读取本文件，按照以下侧重点进行分析。

## 滴滴战法（地铁战法）上下车点判断 —— 预测时必做

在对手动分析的股票做**次日走势预测**时，必须判断该股当天是否处于滴滴战法的上车/下车节点，并在预测结果中标注。

### 判断方法
调用 `core.indicators.algorithms.compute_didi_indicator(open, high, low, close)`，传入该股票按日期升序的完整 OHLC 序列，取**当天（最后一根/目标日）**的信号：
- `buy[当天] == True` → 命中**上车点**（黄框信号，买入位置）
- `sell[当天] == True` → 命中**下车点**（青蓝信号，卖出位置）
- 两者都为 False → 当天不在上下车节点

参考实现：`scripts/run_screen_local.py` 中的 `didi_signal_tag()`。

### 标注规则（与自动选股报告保持一致）
- **只在预测理由/备注里标注**，**不改变方向打分**（方向、置信度仍按原有量价/定式/板块逻辑判断）。
- 未命中：不显示任何滴滴相关内容（不要写"未命中滴滴"之类的话）。
- 写入 `output/manual_predictions/{date}.json` 时，每只股票记录中增加字段 `"didi_signal"`，取值 `"on_board"`（上车）/ `"off_board"`（下车）/ `null`（无信号）。

### 命中时的表现形式（要突出/醒目）
命中滴滴战法时，表现形式必须明显，不能只是一句轻描淡写：
- **对话回复中**：单独用醒目一行强调，例如：
  - 上车：`🚇🟡 **【命中滴滴战法·上车点】买入位置** — {名称}({代码})`
  - 下车：`🚇🔵 **【命中滴滴战法·下车点】卖出位置** — {名称}({代码})`
- 在 `prediction` 文案中：用加粗+🚇徽章前置突出，例如「🚇 **命中滴滴上车点（买入位置）**，…（原预测内容）」。
- 若同时分析多只股票，命中滴滴的标的应在结果开头/汇总处单独点名提示，让用户一眼看到。
