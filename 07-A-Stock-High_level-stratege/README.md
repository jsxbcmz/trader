# Julie 量化 · A股策略工具

> 个人使用 · 回测 + 模拟交易 · 轻量级策略终端

---

## 功能简介

| 模块 | 说明 |
|------|------|
| **回测** | 用历史数据验证策略效果，输出收益曲线、指标和交易记录 |
| **模拟交易** | 实时/准实时行情运行策略，观察信号与持仓变化 |

支持策略：
- **SuperTrend 趋势跟踪**（单股日线，ATR 自适应通道，含 T+1 约束）
- **小市值 ROE（15x 策略）**（月度轮动，ROE>15% + ROA>10%，按市值升序）
- **大盘轮动**（沪深300 + 中证500 成分股，ROE 筛选，月度调仓）

### 数据缓存机制

```
请求数据
    │
    ▼
_cache_get(key, ttl)
    │
    ├── 命中且未过期 ──► 直接返回缓存数据（SQLite kv_cache 表）
    │
    └── 未命中或已过期
            │
            ▼
        调用外部 API
            │
            ▼
       _cache_set(key, value)
       （写入 SQLite，记录时间戳）
            │
            ▼
        返回最新数据
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动 Web 应用

```bash
cd 07-A-Stock-High_level-stratage
streamlit run web/app.py
```

浏览器打开 `http://localhost:8501`，顶部切换 **回测** / **模拟交易**。

### 3. 命令行回测（SuperTrend）

```bash
# 贵州茅台，2020年至今
python strategies/strategy_supertrend_ashare.py --code 600519

# 自定义参数
python strategies/strategy_supertrend_ashare.py \
    --code 000858 --start 20210101 --period 14 --multiplier 2.5
```

## 回测说明

### SuperTrend

- **信号逻辑**：收盘价跌破 ATR 自适应上轨 → 清仓；突破下轨 → 买入
- **T+1 约束**：信号整体延迟 1 个交易日执行
- **成本模型**：买入佣金 0.03%，卖出佣金 + 印花税 0.13%
- **参数推荐**：period=14，multiplier=3.0（震荡市可调高至 4.0）

### 小市值 ROE（月度轮动）

- **选股条件**：ROE > 15%，ROA > 10%，按市值升序取前 N 只
- **调仓频率**：每月月初等权换仓
- **数据说明**：使用当前 TTM 财务数据近似历史信号，结果仅供参考

---

## 模拟交易说明

- 账户状态持久化到 `data/paper_account.json`
- 支持手动买入 / 卖出，强制 T+1 约束
- 点击「刷新行情」更新持仓现价（腾讯行情接口）
- 点击「获取信号」触发当日策略信号计算
- 重置账户会清空所有持仓和交易记录（不可撤销）

## 回测输出文件

每次组合回测完成后自动保存到 `output/{strategy}_{YYYYMMDD_HHMMSS}/`，每次运行独立目录，不会覆盖历史记录。

| 文件 | 内容 |
|------|------|
| `metrics.csv` | 总收益率 / 年化收益率 / 最大回撤 / Sharpe / 胜率 / 持续天数 |
| `portfolio_equity_daily.csv` | 每日组合净值时间序列（date, equity） |
| `portfolio_trades.csv` | 组合级买卖流水，含成交金额 / 手续费 |
| `summary.csv` | 各标的交易次数 / 盈亏次数 / 胜率 / 总收益对比 |

## 数据来源

| 数据类型 | 接口 | 缓存 TTL |
|----------|------|----------|
| 历史 K 线（前复权）| 东方财富 push2his API | 6 小时 |
| 实时行情 | 腾讯行情 qt.gtimg.cn | 无缓存 |
| 基本面（ROE/ROA/市值）| AKShare（同花顺/东方财富）| 24 小时 |
| ST 股票列表 | AKShare | 6 小时 |
| 指数成分股 | AKShare | 24 小时 |

## 注意事项

- 本工具**仅供个人研究使用**，不构成投资建议
- 回测使用当前 TTM 财务数据作历史近似，存在前视偏差
- 实时行情延迟约 15 分钟，不适合高频交易场景
- 不包含实盘接入功能
