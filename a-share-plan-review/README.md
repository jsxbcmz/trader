# A股盘前计划 + 交易复盘 Skill

这个 skill 将两个高频任务合并：
1. 盘前计划
2. 单笔交易复盘

目标是先自动补采尽可能多的有用数据，再输出稳定结构，而不是只复述用户输入。

---

## 文件结构

```text
a-share-plan-review/
├── SKILL.md
├── README.md
├── rules/

    ├── watchlist.json          # 自选股分组配置
    └── requirements.txt        # Python 依赖（requests, pandas, matplotlib）
```

## 能做什么

### 盘前计划

自动优先收集：
- 自选股与观察池
- 隔夜消息 / 公告 / 催化剂
- 集合竞价或前收信息
- 所属板块与板块联动
- 关键阻力 / 支撑
- 市场风格、赚钱效应、北向资金
- **个股量比 + 主力/大单/中单/小单净流入**（模块 8 新增）

输出：
- 一屏摘要
- 今日盘前执行表（含量比、主力流入两列）
- 个股资金流向详情表（超大单/大单/中单/小单分列）
- 赚钱效应 / 风格 / 最值得盯盘的票
- 数据可得性与缺口

### 交易复盘

自动优先收集：
- 标的 / 日期 / 进出场 / 原计划规则
- 同时段指数环境
- 板块联动与风格背景
- 北向 / 板块资金（能取到则取）
- 连亏、主观提前卖出、FOMO 等行为线索
- **当日量比 + 资金流向（主力/大单净流入）**（模块 8 新增）

输出：
- 事实依据
- 规则检查
- 违规点
- 心理模式
- 可量化改进动作
- 当日资金流向子表
- 数据可得性与缺口

## 快速上手

### 安装依赖

```bash
python -m pip install -r requirements.txt
```

依赖包：`requests`, `pandas`, `matplotlib`（均为纯 PyPI 包，无需其他项目）

### 盘前计划

```bash
# 手动指定股票代码
python .github/skills/a-share-plan-review/scripts/collect.py premarket \
  --stocks "600519,300750,002594" --top-n 5 --output reports/

# 使用 watchlist.json 预设分组
python .github/skills/a-share-plan-review/scripts/collect.py premarket \
  --watchlist            # 使用 default 分组
python .github/skills/a-share-plan-review/scripts/collect.py premarket \
  --watchlist core_index # 使用 core_index 分组
```

### 交易复盘

```bash
python .github/skills/a-share-plan-review/scripts/collect.py review \
  --stock "300750" --date 2026-04-13 \
  --entry-time "10:02" --entry-price 198.50 \
  --exit-time "10:20"  --exit-price 196.20 \
  --stop 193.00 --strategy "开盘区间突破" --output reports/
```

### 绩效分析

```bash
python .github/skills/a-share-plan-review/scripts/analyze_trades.py \
  --file trades.csv --commission 0.00015 --stamp 0.0005
```

## 脚本采集内容

| 模块 | 盘前模式 | 复盘模式 | 数据源 |
| ---- | -------- | -------- | ------ |
| 主要指数实时报价 | ✅ | ✅ | 新浪财经 hq.sinajs.cn |
| 自选股实时报价 | ✅ | ✅ | 新浪财经 hq.sinajs.cn |
| 市场广度（涨跌家数/涨停数/成交额） | ✅ | ✅ | 东方财富 datacenter-web |
| 行业板块涨跌幅排行 | ✅ (top_n) | ✅ (top 3) | 东方财富 push2 |
| 北向资金（沪股通 + 深股通） | ✅ | ✅ | 东方财富 push2 |
| 市场热点快讯 | ✅ | — | 东方财富快讯 / 新浪备用 |
| 个股公告 | ✅ (各股 2 条) | ✅ (5 条) | 东方财富公告接口 |
| 涨跌停参考价 & 出场时距涨停空间 | ✅ | ✅ | 计算自前收 |
| **量比 & 换手率** ★新 | ✅ | ✅ | 东方财富 push2 stock |
| **主力/超大单/大单/中单/小单净流入** ★新 | ✅ | ✅ | 东方财富 push2 stock |

### 盘前执行表列说明

| 列 | 说明 |
| -- | ---- |
| 量比 | 当前成交量 / 过去5日同时段均量，>1 表示放量 |
| 主力流入 | 超大单+大单今日净流入（亿），正值表示主力净买入 |

### 优先级评分（满分 12 分）

| 维度 | 权重 | 规则 |
| ---- | ---- | ---- |
| 涨跌幅强度 | 4 分 | ≥5%: 4 \| 2-5%: 3 \| 0-2%: 2 \| 负: 0 |
| 成交额活跃度 | 3 分 | ≥1亿: 3 \| ≥0.1亿: 2 \| 其余: 1 |
| 今开 vs 前收 | 3 分 | 高开≥2%: 3 \| 平开: 2 \| 低开: 1 |
| 主力净流入 ★新 | 2 分 | >0.5亿: 2 \| >0: 1 \| 负或暂缺: 0 |
| **判定** | — | **高 ≥10 / 中 ≥7 / 低 <7** |

## 依赖说明

本 skill 完全自包含，不依赖工作区内任何其他项目文件。

所有规则（来源优先级、新鲜度标签、缺口披露规则）已内联到 `rules/data-collection.md` 第 1.0 节。

外部依赖仅包括三个标准 PyPI 包：

| 包 | 用途 |
| --- | --- |
| `requests` | HTTP 数据采集（collect.py） |
| `pandas` | 交易记录分析（analyze_trades.py） |
| `matplotlib` | 绩效图表生成（analyze_trades.py） |

如果外部数据无法取得，skill 仍然需要输出最低可用结果，并集中披露缺口。
