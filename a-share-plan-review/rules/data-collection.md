# 自动收集数据规则

本文件定义盘前计划与交易复盘两种模式下，应该自动补采哪些有用数据。  
**数据自动采集由脚本完成，无需用户交互。**

---

## 0 自动采集脚本

所有数据采集由 `scripts/collect.py` 负责，运行后自动输出结构化 Markdown 报告。

### 安装依赖

```bash
python -m pip install -r scripts/requirements.txt
```

### 模式 A — 盘前计划

```bash
python .github/skills/a-share-plan-review/scripts/collect.py premarket \
  --stocks "600519,300750,002594,601318" \
  --top-n 5 \
  --news-n 8 \
  --output reports/
```

| 参数 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--stocks` | 自选股代码，逗号分隔（必填） | — |
| `--top-n` | 板块涨跌榜取前 N 条 | 5 |
| `--news-n` | 快讯条数 | 8 |
| `--output` | 报告输出目录 | reports/ |
| `--no-file` | 只打印到终端，不写文件 | — |

### 模式 B — 交易复盘

```bash
python .github/skills/a-share-plan-review/scripts/collect.py review \
  --stock "300750" \
  --date 2026-04-13 \
  --entry-time "10:02" --entry-price 198.50 \
  --exit-time "10:20"  --exit-price 196.20 \
  --stop 193.00 \
  --strategy "开盘区间突破" \
  --output reports/
```

| 参数 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--stock` | 单只标的代码（必填） | — |
| `--date` | 交易日期 YYYY-MM-DD | 今日 |
| `--entry-time` | 进场时间，如 10:02 | — |
| `--entry-price` | 进场价格 | — |
| `--exit-time` | 出场时间 | — |
| `--exit-price` | 出场价格 | — |
| `--stop` | 计划止损价 | — |
| `--strategy` | 策略类型 | 未指定 |
| `--output` | 报告输出目录 | reports/ |
| `--no-file` | 只打印到终端，不写文件 | — |

### 脚本采集内容

| 模块 | 盘前模式 | 复盘模式 | 数据源 |
| ---- | -------- | -------- | ------ |
| 主要指数实时报价 | ✅ | ✅ | 新浪财经 hq.sinajs.cn |
| 自选股实时报价 | ✅ | ✅ | 新浪财经 hq.sinajs.cn |
| 市场广度（涨跌家数/涨停数/成交额） | ✅ | ✅ | 东方财富 datacenter-web |
| 行业板块涨跌幅排行 | ✅ (top_n) | ✅ (top 3) | 东方财富 push2 |
| 北向资金（沪股通 + 深股通） | ✅ | ✅ | 东方财富 push2 |
| 市场热点快讯 | ✅ | — | 东方财富快讯 / 新浪备用 |
| 个股公告 | ✅ (首只) | ✅ | 东方财富公告接口 |
| 涨停/跌停参考价 & 出场时距涨停空间 | ✅ | ✅ | 计算自前收 |
| **量比 & 换手率** | ✅ | ✅ | 东方财富 push2 stock (f11, f10) |
| **主力/超大单/大单/中单/小单净流入** | ✅ | ✅ | 东方财富 push2 stock (f62, f66, f69, f72, f75) |

### 输出报告

报告自动保存到 `reports/YYYY-MM-DD_盘前计划.md` 或 `reports/YYYY-MM-DD_复盘_<标的>.md`。  
同日同类型多次运行自动追加数字后缀，不覆盖。

## 1 统一采集原则

1. 先用用户输入。
2. 用户未提供时，再补采公开可验证数据。
3. 数字遵循以下来源优先级、新鲜度标签与缺口规则（见 1.0 节）。
4. 自动采集失败时，集中列在"数据可得性与缺口"。
5. 不因为少量缺口就拒绝输出。

---

## 1.0 数据规则（内联）

### 来源优先级

**行情数据（按优先级）：**
1. 上交所 / 深交所 / 中金所 官方页面
2. 东方财富 eastmoney.com
3. 同花顺 10jqka.com.cn
4. 新浪财经 finance.sina.com.cn
5. 腾讯自选股 / 雪球（补充）

**新闻来源（同时覆盖）：**
财联社、华尔街见闻、第一财经、界面新闻、中国证券报、证券时报、上海证券报、上交所公告、深交所公告、东方财富快讯

### 新鲜度标签

所有数字必须带标签：

| 延迟 | 标签 |
| ---- | ---- |
| ≤ 30 分钟 | `[实时]` |
| 30 分钟 – 3 小时 | `[延迟 HH:MM CST]` |
| > 3 小时 | 改用 `[前收: DD MMM YYYY]` |

示例：`3,245 [实时] Source: 东方财富`

### 数字获取顺序

1. 先取实时数据（新鲜度 ≤ 30 分钟）。
2. 双源交叉校验：两源一致直接用；差异明显则同时展示并注明"来源有分歧，按保守口径"。
3. 实时不可得时退回前收数据。
4. 仍不可得时明确写缺失，給出官方来源入口链接，字段不得留空。

**绝对禁止：先写后查 / 编造 / 猜测 / 外推 / 使用评论文章的二手数字。**

### 缺口集中披露规则

同一模块缺失 ≥ 2 项时：
- 模块内只保留可得关键数字与结论。
- 所有缺失项统一移到报告末尾的"数据可得性与缺口"区块，不在每个字段重复写"暂缺"。

### 代理指标规则

主指标不可得时可用代理，但必须在数字旁标注 `[代理]`：

| 主指标 | 代理指标 |
| ------ | -------- |
| A50 期货 | 上证50现货 或可验证 A50 CFD |
| 沪金 / 沪银主力 | 伦敦金银 或 COMEX 金银 |
| 期权 PCR / Max Pain | 300ETF 价格 + 成交变化 + 波动率 |

## 2 A 模式：盘前计划采集清单

### 必采

1. 自选股列表或观察池
2. 隔夜新闻 / 公告 / 业绩 / 政策催化
3. 集合竞价信息；若无，则退回前收、昨量、昨高低点
4. 所属板块与板块强弱
5. 关键位：前高、前低、阻力、支撑、是否接近涨停价
6. 大盘环境：
   - 上证指数
   - 创业板指
   - 沪深300
   - 两市成交额或预估活跃度
   - 涨跌家数 / 涨停跌停 / 高位股反馈（能取到则取）
7. 资金风格：
   - 北向资金
   - 权重 / 成长 / 题材风格偏好

### 选采

1. 竞价金额
2. 竞价量比
3. 封单强度（若为强势股）
4. 近 3-5 日趋势结构
5. 是否有减持、监管、澄清风险

### 输出映射

自动采集到的数据，优先映射到以下字段：
- 催化剂
- 竞价/量价强弱
- 板块联动
- 关键阻力
- 关键支撑
- 适合的交易模式
- 是否适合隔夜
- 优先级
- 放弃理由

## 3 B 模式：交易复盘采集清单

### 必采

1. 标的名称 / 代码
2. 交易日期
3. 进场价、出场价、计划止损、计划规则
4. 当时的板块联动强弱
5. 同时段指数背景：
   - 上证指数
   - 创业板指
   - 沪深300
6. 当日市场风格：
   - 权重 / 成长 / 题材
   - 是否处于情绪修复 / 高潮 / 分歧 / 退潮

### 优先补采

1. 北向资金方向
2. 板块资金流向
3. 当时是否有新闻催化延续
4. 距离涨停 / 跌停空间
5. 当日是否为连亏后的第 2 / 第 3 笔交易
6. 是否存在主观提前卖出、追高、逆势抄底等行为

### 图片不足时的处理

1. 截图看不到的数据，不脑补。
2. 如果图片无法确认 K 线细节，只写“截图无法确认”。
3. 若用户给了成交时间，优先围绕该时段补采市场背景。

### 输出映射

自动采集到的数据，优先映射到以下结构：
- 事实依据
- 规则检查
- 违规点
- 心理模式
- 可量化改进动作
- 数据可得性与缺口

---

## 4 最低可用输出

### 盘前计划最低要求

1. 至少 3 只观察标的
2. 至少 1 条消息或催化来源
3. 至少 2 个指数环境判断
4. 至少 1 个板块强弱结论
5. 至少 1 个缺口说明

### 交易复盘最低要求

1. 至少说明进场是否符合规则
2. 至少说明出场是否符合规则
3. 至少识别 1 个纪律问题或确认无明显纪律问题
4. 至少给 2 条可量化改进动作
5. 至少 1 个缺口说明
