## 1. 战法定位

### 1.1 一句话定义
**B1 = 主力放量建仓后，缩量回调到关键均线附近，出现"分歧转一致"的极致缩量小 K 线，预示主升浪即将启动的左侧买点。**

### 1.2 适用场景
| 场景 | 是否适用 | 说明 |
|------|---------|------|
| 牛市右侧（白线在黄线之上） | ✅ 最佳 | 文档反复强调"牛市做交易和波动" |
| 震荡市 | ⚠️ 谨慎 | 需配合大盘节奏，盈亏比下降 |
| 熊市/破位下跌 | ❌ 禁用 | 文档明确"破位放量大跌严禁抄底" |
| 北交所 | ❌ 禁用 | 文档明确排除（通过 stocklist.csv 股票池管控） |

### 1.3 盈亏比目标
- 向上空间：10% ~ 20%
- 向下空间：2% ~ 5%
- 目标盈亏比：≥ 5:1

## 2. 核心理论

### 2.1 分歧转一致（核心机制）

| 状态 | K 线特征 | 量能 | 含义 |
|------|---------|------|------|
| 分歧 | 大阳线 / 大阴线 / 长上下影 | 放量 | 多空激烈博弈，方向未明 |
| 一致 | 小阴小阳（实体 ≤ 2%） | 极致缩量（地量） | 多空达成短暂平衡，反转信号 |

**B1 入场点 = 分歧后突然变成一致的那根 K 线。**

### 2.2 N 型结构

主力拉升路径：`启动放量 → 阶段震荡洗盘 → 再启动放量`，每次回调都是抬升市场平均成本。

B1 锁定的是 N 型结构的**底部第二个支点**——回调结束、二次启动前。

### 2.3 黄线 / 白线（均线体系）

| 名称 | 周期 | 作用 |
|------|------|------|
| 黄线（大哥线） | MA250 | 操作生命线，**原则上不做黄线以下的票** |
| 白线 | MA60 | 短期趋势线，B1 通常在白线附近企稳 |

文档原话："大盘终将回踩黄线，否则行情无法长远。"

### 2.4 完美形态四变种

| 变种 | 形态 | 案例 | 触发条件特点 |
|------|------|------|-------------|
| 完美一 | 标准缩量回调 → 极致缩量小 K | 华纳药业（娜娜图） | 振幅小、缩量到地量 |
| 完美二 | 长时间横盘"时间换空间" | 澄天伟业 | 主力介入深，洗盘时间长 |
| 完美三 | 红肥绿瘦箱体震荡 | 新瀚新材 | N 型压缩为方块，高控盘 |
| 完美四 | 顶部缩量上涨（高控盘庄股） | 昂利康 | 仅适用于市场 4500 点以上 |

> **当前 v1.0 公式主要捕捉"完美一"和"完美二"，"完美三/四"留待后续版本扩展。**

## 3. 选股条件设计

### 3.1 总览

公式分为 **5 大类共 13 项条件**，全部满足才触发 B1 信号：

```
A. 历史结构（前期主力建仓痕迹） ── 5 项
B. 当日反转 K 线（核心信号）   ── 3 项
C. 位置感（均线相对位置）       ── 2 项
D. 出货信号过滤                ── 2 项
E. 时序（确认在回调段）         ── 1 项
```

### 3.2 详细条件矩阵

| 编号 | 类别 | 公式标识 | 含义 | 阈值 | 文档依据 |
|------|------|----------|------|------|---------|
| A1 | 历史结构 | `PLRY_CNT` | 前期放量阳线次数 | 14 日 ≥2 或 28 日 ≥3 | "主力放量启动"反复出现 |
| A2 | 历史结构 | `YANGYIN_OK1/2` | 阳量 > 阴量 | 28 日 1.65×、14 日 2.25× | 筹码累积、主力锁仓 |
| A3 | 历史结构 | `J_OK` | KDJ 超卖 | J ≤ 13 | 07-12"KDJ 配合量能" |
| A4 | 历史结构 | `THREE_SUM_OK` | 量能行为模式综合得分 | 首次放量+连续放量+缩量回调 ≥3 | 主力建仓的复合特征 |
| A5 | 历史结构 | `MVOK` | 流通市值 | ≥ 40 亿 | 09-05"避免成交量过小的个股" |
| B1 | 当日 K 线 | `TODAY_BODY` | 实体大小 | ≤ 2% × 前收 | 09-05"K 线实体在 -2%~+2%" |
| B2 | 当日 K 线 | `TODAY_CHG` | 涨跌幅 | ≤ ±2.5% | 09-04"当日涨幅 -2% 到 +1.8%" |
| B3 | 当日 K 线 | `TODAY_AMP` | 振幅 | ≤ 4.5% | 09-05"主板振幅 4% 以内" |
| B4 | 当日量能 | `TODAY_SHRINK` | 当日缩量到地量 | 比前日 ≤85% 且接近 20 日地量 ×1.3 | 09-04"极致缩量"、09-05"地量" |
| C1 | 位置感 | `POS_ABOVE_HUANG` | 黄线之上（硬约束） | C > MA250 | 09-03"黄线之上才具备操作意义" |
| C2 | 位置感 | `POS_NEAR_BAI` | 接近白线 | 距 MA60 ≤ 6% | 09-03"回调至黄线或白线附近" |
| D1 | 排除 | `GOOD28` | 28 日内无高位放量阴线 | 开盘 ≥ 28 日区间 95%+ 收阴 + 量 ≥1.15× | 07-12 S1 卖点反向过滤 |
| D2 | 排除 | `MAX28_OK` | 28 日最大量必须是阳线 | 最大量日不能是真阴 | 09-06"放量大阴 = 出货" |
| E1 | 时序 | `QUIET_OK` | 最近 5 日无大放量 | `COUNT(PLRY,5)=0` | 07-12"已回调"而非"正在涨" |

### 3.3 条件分组逻辑

```
┌─────────────────────────────────────────────────────────────┐
│                     原 A1（历史结构合格）                     │
│  PLRY_CNT ∧ (YANGYIN_OK1∧THREE_SUM_OK ∨ YANGYIN_OK2)        │
│  ∧ J_OK ∧ MVOK ∧ GOOD28 ∧ MAX28_OK                          │
└─────────────────────────────────────────────────────────────┘
                              ∧
┌─────────────────────────────────────────────────────────────┐
│                  新增：当日反转 K 线（核心）                  │
│        TODAY_BODY ∧ TODAY_CHG ∧ TODAY_AMP ∧ TODAY_SHRINK    │
└─────────────────────────────────────────────────────────────┘
                              ∧
┌─────────────────────────────────────────────────────────────┐
│                       新增：位置感                            │
│              POS_ABOVE_HUANG ∧ POS_NEAR_BAI                  │
└─────────────────────────────────────────────────────────────┘
                              ∧
┌─────────────────────────────────────────────────────────────┐
│                       新增：时序确认                          │
│                          QUIET_OK                            │
└─────────────────────────────────────────────────────────────┘
                              ∧
┌─────────────────────────────────────────────────────────────┐
│                    辅助：综合均线（弱约束）                   │
│                          QL_OK                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
                          B1 = TRUE
```

## 5. 工程实现细节

### 5.1 数据要求

| 项 | 要求 | 来源 |
|---|------|------|
| 历史长度 | ≥ 250 个交易日 | Tushare daily |
| 必备字段 | OHLC、volume、CAPITAL（流通股本） | Tushare daily + daily_basic |
| 数据频率 | 日线 | 已有 [stock_daily_data/](../stock_daily_data/) |

> ⚠️ `MV` 公式用了 `CAPITAL`，需确认 [data_loader.py](../app/data_loader.py) 在加载时已附带流通股本字段；如未附带，需在 [history_updater.py](../app/history_updater.py) 中补齐。

### 5.2 股票池（公式外，Python 层处理）

直接使用 [stocklist.csv](../stocklist.csv) 作为选股池，不再单独编写板块过滤逻辑。该文件已包含经过筛选的可交易标的列表（已排除北交所、新三板等不适用板块）。

选股引擎在运行 B1 公式前，只需读取 `stocklist.csv` 中的股票代码列表作为输入即可。

### 5.3 与现有选股系统集成

| 集成点 | 说明 |
|-------|------|
| 表达式解析 | 使用 [core/expression/](../core/expression/) 现有通达信解析器 |
| 缓存层 | 复用 [core/screening/service.py](../core/screening/service.py) 的 `screen_with_cache()` |
| 进度反馈 | 使用现有的断点续选机制 |
| 模板存储 | 在 [templates.json](../templates.json) 中保存为 `B1_v1.0` 模板 |
| UI 入口 | [选股页](../app/pages/screening_page.py) + [定式验证页](../app/pages/brick_pattern_page.py) |

### 5.4 性能预估

- 单只股票：13 项条件，所有指标都是 O(N) 滑动窗口，单只 < 5ms
- 全市场（约 5000 只）：预估 25 秒以内
- 触发率预估：每日全市场 0~5 只（严格条件下，符合"宁缺毋滥"）

## 6. 验证方案

### 6.1 历史回测

使用 [定式验证页](../app/pages/brick_pattern_page.py) 跑历史回测，统计：

| 指标 | 目标值 | 不达标处理 |
|------|-------|-----------|
| 触发样本数（近 1 年） | ≥ 30 例 | 触发太少 → 放宽阈值（见 7.1） |
| T+5 胜率（涨幅 > 0） | ≥ 65% | 胜率太低 → 加严过滤（如提高 MV 门槛） |
| 平均盈亏比 | ≥ 3:1 | 盈亏比太低 → 检查止损位设置 |
| 最大单笔回撤 | ≤ 8% | 回撤太大 → 加强 D 类排除项 |

### 6.2 关键案例对照

文档提到的成功/失败案例，公式应该能区分：

| 案例 | 文档结论 | 公式应输出 |
|------|---------|-----------|
| 华纳药业（B1 标准案例） | 应触发 | `B1 = TRUE` |
| 中科金财（B1 介入） | 应触发 | `B1 = TRUE` |
| 顺丰、阿胶（破位放量大跌） | 严禁抄底 | `B1 = FALSE`（GOOD28 排除） |
| 南华期货（高位游资博弈） | 规避 | `B1 = FALSE`（MAX28_OK 或 D1 排除） |
| 宁波精达（生不逢时止损案例） | 应触发买入信号但需止损 | `B1 = TRUE`（逻辑无误，止损靠交易系统） |

### 6.3 与原 v0 公式对比

| 维度 | v0（原公式） | v1（改进版） |
|------|-------------|-------------|
| 触发数量 | 多（无当日 K 线约束） | 显著减少 |
| 误报率 | 较高（会选到拉升中的票） | 较低 |
| 与文档贴合度 | 60% | 90%+ |
| 调参灵活性 | 低 | 高（见 7.1） |

## 7. 调参与扩展

### 7.1 调参档位（按严格 → 宽松排序）

如果 v1 触发太少，按以下顺序放宽：

| 档位 | 调整 | 影响 |
|-----|------|------|
| L1 | `TODAY_AMP` 4.5% → 6.5% | 兼容创业板，触发数 +30% |
| L2 | `POS_NEAR_BAI` 6% → 9% | 容纳更深回调，触发数 +20% |
| L3 | `QUIET_OK` 5 日 → 3 日 | 允许刚回调的票，触发数 +50% |
| L4 | `J_OK` J≤13 → J≤20 | 放宽超卖，触发数 +40% |
| L5 | `MVOK` 40 亿 → 30 亿 | 兼容中盘，触发数 +25% |

> **不建议放宽的硬约束**：`POS_ABOVE_HUANG`（黄线之上）、`MAX28_OK`（最高量必须是阳）、`GOOD28`（无高位放量阴）。这三条破坏后等于偏离 B1 战法本质。

### 7.2 待扩展形态（v2 路线图）

| 形态 | 当前覆盖 | v2 需新增 |
|------|---------|---------|
| 完美一（标准缩量回调） | ✅ | — |
| 完美二（时间换空间） | ✅（部分） | 增加横盘天数判断（HHV-LLV 区间小） |
| 完美三（红肥绿瘦箱体） | ❌ | 需新增"小区间高控盘"识别 |
| 完美四（顶部缩量上涨） | ❌ | 需识别市场环境 + 高控盘庄股特征 |

## 8. 风险与已知局限

### 8.1 战法本身的局限
1. **B1 是左侧买点**：可能买在阶段性低点的"半山腰"，必须严格止损
2. **依赖大盘环境**：熊市或破位中无效，需人工判断大盘阶段后再决定是否启用
3. **不适合超短线**：B1 是波段战法，预期持有 1~4 周

### 8.2 公式实现的局限
1. **公式无法读 symbol 前缀**：板块过滤必须在 Python 层
2. **无法识别停牌/复牌**：需在 [data_loader.py](../app/data_loader.py) 处理
3. **CAPITAL 字段精度**：通达信公式中的 `CAPITAL` 单位是手，已乘 100 转股，但若 Tushare 数据未对齐需重新校准
4. **完美三/四未覆盖**：仅适用大部分常见 B1 形态

### 8.3 不是 B1 但可能误触发的形态
- 单针探底反弹后的小阴小阳（位置在黄线下，会被 C1 过滤）
- 长期横盘破位前的最后一个小 K（会被 GOOD28 + MAX28_OK 过滤）
- 涨停板后第二日的小阴线（会被 QUIET_OK 过滤）
